\chapter{统一DSE框架：从物理约束到线性规划}\label{chap:overview}

第~\ref{chap:background}章展示了晶圆级交换机面临的多类物理约束及其紧耦合特征。
本章介绍本文的核心方法论：如何将这些看似无关的约束统一到一个数学框架中。

我们不从结论开始。我们从一个具体的架构问题出发——
给定一个技术选型（拓扑、裸片、封装、冷却），如何判断它是否物理可行？——
然后逐一考察三类约束在这个问题中扮演的角色。
读者将看到，每一类约束从最粗糙的估计到最精细的建模，
最终都收敛到同一个数学形式：关于链路负载向量$\mathbf{L}$的线性不等式。
三类约束分析完成后，我们展示它们的统一结构——以及这一统一性赋予的"梯度配置"能力。
