\chapter{结论与展望}\label{chap:conclusion}

\section{本文总结}

本文提出了一套面向晶圆级交换机早期设计空间探索的统一线性规划框架。
核心贡献包括：

\begin{enumerate}
    \item \textbf{统一数学框架}。我们证明，晶圆级交换机的三类物理约束——交换性能、几何布局、功耗散热——尽管物理本质不同，但都可以表示为链路负载向量$\mathbf{L}$上的线性不等式。
    这一统一性来自物理规律（流量、lane数、功耗、温度对链路负载的线性依赖），而非工程巧合。
    框架将DSE从"并行运行多个独立检查"变成"构建并求解一个LP"。

    \item \textbf{梯度配置}。每族约束支持多种精度级别，精度升级只替换系数矩阵，不改变框架结构。
    这一性质使架构师可以在速度与精度之间自由选择，精度升级成为数据驱动的决策。

    \item \textbf{设计梯度分析}。LP对偶变量提供每个物理约束的影子价格，
    $B_{\max}$解析公式从一次LP求解中反推物理带宽天花板。
    两者共同构成了从"是否可行"到"差在哪、怎么改"的完整设计指导信息。

    \item \textbf{实验发现}。在Dragonfly拓扑家族上的DSE实验揭示了bump预算是晶圆级交换机的首个物理天花板，
    $B_{\max} \propto 1/N$的缩放律为大规模扩展提供了定量依据。
    在$N \le 30$和800 Gbps的典型工作点下，物理约束有80倍以上松弛。
\end{enumerate}

\section{局限与展望}

\textbf{规模限制}：当前Valiant LP的实用上限约为$N=30$。混合精度策略和分解求解方法是扩展到$N > 100$的可行路径。

\textbf{物理建模}：布线约束（几何L2）和3D堆叠的参数标定需要与工艺团队协作。
本文的线性框架为这些扩展提供了数学基础——纳入新约束只需增加矩阵行数。

\textbf{验证}：LP给出的$t^* \le 1$是无阻塞的\textbf{必要条件}（假设完美流控），实际系统需乘实现效率$\eta_{\text{impl}} \approx 0.8$。
与cycle-accurate仿真和工业设计数据的对标验证是重要的下一步。

本文的核心贡献不在于提出新拓扑、新路由或新封装，而在于证明：
\textbf{晶圆级交换机DSE中最困难的部分——多物理约束的耦合判断——可以被一个线性规划干净地封装。}
这一认识为晶圆级系统的早期设计探索提供了一个新的起点。
