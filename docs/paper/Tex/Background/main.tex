\chapter{背景：晶圆级物理架构、按位置的约束与无阻塞语义}\label{chap:background}

本章建立理解本文框架所需的前置知识，分三部分。
首先说明晶圆级交换机的三层物理架构（Die--Interposer / Interposer--Substrate / 晶圆级集成）；
其次按物理位置梳理七组核心物理约束（on-die / $\mu$bump / 布线 / 热 / C4 / 组间 / die 缩放），
对每组给出物理本质与建模思路；
最后澄清本文「无阻塞」的确切语义——无阻塞\textbf{潜能}，而非保证。
