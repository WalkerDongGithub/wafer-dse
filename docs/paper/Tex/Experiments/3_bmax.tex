\section{$B^*$ 分析：二分搜索与事后闭式瓶颈识别}\label{sec:bmax}

\textbf{论证目标。}
展示框架的区分力：对不同设计点，$B^*$ 与绑定约束给出明确的瓶颈定位——
不是「这个设计可不可行」，而是「这个设计的极限在哪、先撞哪堵墙」。
这一信息直接指导技术路线规划。

\textbf{论证逻辑。}
若只问「目标带宽下是否可行」，多个设计点可能返回同一答案，初筛失去区分力。
因此换一个问法：\textbf{不是「在目标带宽下是否可行」，而是「最多能撑到多高带宽才被物理约束杀死」}。
二分搜索求 $B^*$ 后，再取最后一次可行解 $\mathbf{L}^*$，
用事后闭式 $\lambda_j = 1/(A_j\cdot\mathbf{L}^*)$（式~\eqref{eq:sens-lambda}）识别先绑定约束。

\textbf{实验设计。}
对一组拓扑分别二分搜索 $B^*$（式~\eqref{eq:unified-lp} + 第~\ref{sec:ov-bisection}节），
并把 $B^*$ 分解为单约束天花板：$B^*_{\text{bump}}$（仅 $\mu$bump 约束，式~\eqref{eq:ubump}）与
$B^*_{\text{thermal}}$（仅热约束，式~\eqref{eq:thermal}），
比较二者的绑定顺序与松弛余量，再算归一化影子价格比 $\nu_{\text{bump}}/\nu_{\text{thermal}}$（第~\ref{sec:sens-norm}节）。
