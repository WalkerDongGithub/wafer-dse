\section{保真度：热 L0/L1 的判定一致性}\label{sec:fidelity}

\textbf{论证目标。}
验证梯度配置（第~\ref{sec:ov-linearize}节）的实用价值：
低精度粗筛（热 L0：全局功耗 $\mathbf{1}^T\mathbf{P}\le A_{ip}\,q_{\max}$）与
细粒度模型（热 L1：稳态热网络式~\eqref{eq:thermal}）的判定是否一致，
以及在何种安全裕度下可自信使用低精度。

\textbf{实验设计。}
对同一组设计点，分别用热 L0 与热 L1 求解 $B^*$ 与可行性判定，比较二者差异。
核心指标：L0 的 $B^*$ 相对 L1 是更保守（更低、更安全）还是更乐观（更高、有风险）。

\textbf{论证逻辑。}
L0 把功耗集总到整个 interposer 面积上粗筛，只约束总功耗、忽略温度梯度。
它不刻画局部热点，因此理论上不应比 L1 更乐观（L0 更保守）——这一方向若被实验证实，
则 L0 的「不可行」判定是可靠的（L0 淘汰的，L1 一定也淘汰），
而 L0 的「可行」判定需 L1 复核（L0 可行的，L1 可能仍不可行）。
由此形成\textbf{数据驱动的精度升级策略}：先跑 L0 $\to$ 观察 slack $\to$ 仅当 slack 低于阈值时升级到 L1。
精度升级成为数据驱动的决策，而非方法论绑定。
