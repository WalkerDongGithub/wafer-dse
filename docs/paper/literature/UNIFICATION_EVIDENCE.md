# 核心主张的文献佐证：三类约束在 L 上的统一性

> 本文唯一的新主张：性能、几何、功耗三类物理约束可以统一表示为链路负载向量 L 上的线性不等式。以下逐族论证这一统一性不是我们的发明，而是物理规律的必然结果——我们只是第一个把它指出来的人。

---

## 0. 论证结构

三类约束 → 三个独立物理领域 → 三组独立文献各自验证了"物理量对链路负载的依赖是线性的" → 我们将它们放到同一张表里 → 发现它们都是 L 的线性不等式 → 这就是统一。

**我们的贡献不是推导了任何一个公式。我们的贡献是第一个把三组公式放在一起，指出它们共享同一个变量和同一种数学结构。**

---

## 1. 性能约束：流量 → L → t ≤ 1

### 物理链条
排列矩阵（最坏流量模式） → 双随机矩阵（BvN 松弛） → Valiant 分流（最优路由） → 链路负载 L → min max L = t

### 每一步的文献佐证

| 步骤 | 物理断言 | 佐证文献 | 文献给出的结论 |
|------|---------|---------|---------------|
| 排列 → 双随机 | 双随机多面体的顶点恰好是排列矩阵 | Birkhoff 1946 [17] | 连续 LP 松弛不损失精度——这是数学定理，不是工程近似 |
| 双随机 → L | 链路负载 = 分流变量的线性组合 | Valiant 1982 [18]、Dally & Towles [10] | Valiant 两段式路由中，每条链路的负载是经过它的分流量之和——这是路由协议的定义，不是近似 |
| L → t | min max L 是 LP | Ngo 等人 INFOCOM 2010 [16] | 交换网络的非阻塞条件可以用 LP 对偶性统一分析——该方法在 Clos/Banyan 网络上已得到系统验证 |

### 关键论证

BvN 定理告诉我们：离散排列搜索等价于连续 LP。这是 Birkhoff 在 1946 年证明的数学事实，不受任何工程假设影响。

Valiant 路由告诉我们：自适应分流可以平滑链路负载，最优分流方案可以通过 LP 求解。这是 Valiant 在 1982 年提出的路由范式，Dragonfly 拓扑的原始论文（Kim, ISCA 2008 [9]）明确采用了 Valiant 作为默认自适应路由。

Ngo 等人（INFOCOM 2010）告诉我们：交换网络的非阻塞分析可以用 LP 对偶性统一处理——虽然他们的应用场景是 Clos/Banyan 而不是晶圆级交换机，但方法论上确立了"LP 是分析交换网络可行性的正确数学工具"。

**性能约束是 L 的线性函数——这个结论来自 Birkhoff 定理（数学）、Valiant 路由（协议定义）和 Ngo 的 LP 方法论（先例）。**

## 2. 几何约束：L → lane 数 → bump 占用 → M·L ≤ b

### 物理链条
链路负载 L → 需要的物理 lane 数 = L × B/R → 每个裸片的信号 bump 需求 = Σ incident 链路的 lane 数 → 信号 bump + 电源 bump ≤ 总 bump 预算

### 每一步的文献佐证

| 步骤 | 物理断言 | 佐证文献 | 文献给出的结论 |
|------|---------|---------|---------------|
| L → lane 数 | 每条链路需要 L×B/R 条物理 lane | UCIe 2.0 [3] | 每 lane 速率为 16/32/64 GT/s，端口带宽 B 除以每 lane 速率 R 得到 lane 数——这是 UCIe 协议的定义 |
| lane → bump | 每条 lane 需要一个信号 μbump | UCIe 2.0 [3] | μbump 的物理定义和 pitch 规范——lane-to-bump 是一一对应关系 |
| 信号 bump + 电源 bump | 同一裸片上两类 bump 竞争总面积 | Electrical-Thermal Co-Simulation [15] | 电源 bump 需求 = P/(V·I)，信号和电源在同一 bump 阵列中零和竞争 |
| Σ ≤ budget | per-die 不等式的矩阵形式 M·L ≤ b | 本文推导 | 将以上三步代入即得——每个系数都有物理来源 |

### 关键论证

这一族约束的线性性来自一个简单事实：**每个物理量都是乘出来的**。

L × (B/R) = lane 数。lane 数 × 1 bump/lane = bump 需求。L 的系数 = B/R——端口带宽除以每 lane 速率，两个都是常数（由外层技术选型决定）。

矩阵 M 的元素 M_{v,e} = B/R（当链路 e incident 到裸片 v）或 0（否则）。这是 incidence 矩阵的一个缩放版本——incidence 矩阵本身是线性代数的基本工具。

**几何约束是 L 的线性函数——这个结论来自 UCIe 协议定义的 lane 映射关系（一一对应 × 常数系数）和 incidence 矩阵的数学定义。**

## 3. 功耗约束：L → 功耗 → 温度 → C·L ≤ d

### 物理链条
链路负载 L → 物理层功耗 P = Σ L × P_lane × B/R → 热传导方程 ∇·(k∇T) + q̇ = 0 → 温度 T = G⁻¹(P₀ + C·L + b) → T ≤ T_max 和 ΔT ≤ ΔT_max

### 每一步的文献佐证

| 步骤 | 物理断言 | 佐证文献 | 文献给出的结论 |
|------|---------|---------|---------------|
| L → 功耗 | 每条 lane 消耗 P_lane 瓦特 | UCIe 2.0 [3]、OIF-CEI-5.1 [4] | UCIe: 0.25--0.6 pJ/bit → 功耗 = 速率 × 能效；OIF-CEI: VSR/MR/LR 的每 lane 功耗等级 |
| 功耗 → 温度 | 稳态热方程 ∇·(k∇T) + q̇ = 0 | MFIT 2025 [14] | 热传导方程是线性 PDE——温度 T 对热源 q̇ 的依赖天然是线性的 |
| T → 线性不等式 | T = G⁻¹(P₀ + C·L + b) | MFIT 2025 [14]、Berman & Plemmons [19] | G 是 M-矩阵，G⁻¹ ≥ 0（所有元素非负）——物理含义：功耗增加，温度只升不降（正线性单调性） |
| ΔT ≤ ΔT_max | 温差也是 L 的线性函数 | MFIT 2025 [14] | ΔT_ij = (G⁻¹_i - G⁻¹_j)(P₀ + C·L + b)——两个线性函数的差还是线性函数 |

### 关键论证

这一族约束的线性性来自**热传导方程本身的数学性质**。

热传导的稳态方程 ∇·(k∇T) + q̇ = 0 是线性 PDE——这不是我们的假设，这是物理定律。离散化后 T = G⁻¹(P₀ + C·L + b)，其中 G⁻¹ 是热导矩阵的逆。因为热源项 q̇ = P_lane × L × B/R 是 L 的线性函数，所以温度 T 是 L 的线性函数。

MFIT 论文 [14] 验证了：对于 2.5D/3D chiplet 系统，HotSpot 7.0 的稳态温度预测与商业 CFD 工具的误差在 5% 以内。这意味着用线性热网络近似晶圆级系统的热行为是工程上已验证的，不是我们的简化。

Berman & Plemmons [19] 证明：M-矩阵的逆所有元素非负——G⁻¹ ≥ 0。这一性质的物理含义是：任何位置增加功耗，任何位置的温度只升不降。这意味着我们只需要检查最坏情况（TDP + 稳态）——如果通过，所有次坏情况自动通过。

**功耗约束是 L 的线性函数——这个结论来自热传导方程的线性性（物理定律）、MFIT 验证的工程精度（同行评审）和 M-矩阵的保序性（数学定理）。**

## 4. 统一性的论证

### 三族约束的数学形式对比

| 约束族 | 物理来源 | 数学形式 | 线性性的来源 |
|--------|---------|---------|-------------|
| 性能 | Birkhoff 定理 + Valiant 路由 | Σ_{path} f ≤ t（线性不等式） | 路由协议定义 + 数学定理 |
| 几何 | UCIe lane 映射 + incidence 矩阵 | M·L ≤ b（矩阵不等式） | 物理量是常数乘 L |
| 功耗 | 热传导 PDE + M-矩阵保序性 | C·L ≤ d（矩阵不等式） | 物理定律（线性 PDE） |

### 关键观察

三族约束来自三种完全不同的物理：
- 性能来自**组合数学**（排列、双随机矩阵、BvN 分解）
- 几何来自**封装工程**（bump pitch、lane 映射、incidence 关系）
- 功耗来自**连续介质物理**（热传导 PDE、M-矩阵）

但它们最终都收敛到同一个形式：**L 上的线性不等式**。

这不是因为我们设计了统一的接口。这是因为物理量（流量、lane 数、功耗、温度）对链路负载 L 的依赖天然是线性的。流量是 L 本身（定义），lane 数是 L × 常数（物理协议），功耗是 L × 常数（物理协议），温度是功耗的线性函数（物理定律）。线性性不是我们加上去的——它本来就存在，我们只是把它指出来。

### 统一性的先例

Ngo 等人（INFOCOM 2010）[16] 已经证明了"LP 对偶性可以统一分析不同类型交换网络的非阻塞条件"。他们的工作覆盖了 circuit switching、multirate switching 和 photonic switching，跨越 Clos 和 Banyan 两种架构。这表明：**用 LP 统一不同物理场景下的可行性分析，在交换网络领域有方法论先例**。

本文的贡献是将这一方法论从"不同类型交换网络"扩展到"晶圆级交换机的多物理约束"——统一的对象从"网络架构"变成了"物理维度"。数学工具是同一个（LP），但统一的维度不同。

| lane 数 = L × B/R | 行业标准（UCIe 2.0） | 不能——这是标准 |

| **三者在 L 上统一为线性不等式** | **以上所有文献 + Ngo 的 LP 方法论先例** | **这是本文的贡献——但我们能证明它不是巧合，是物理必然** |

本文的 contribution 不是"定义了一个新的无阻塞判据"，不是"推导了 bump 预算公式"，不是"发明了热网络模型"。本文的 contribution 是：**把三个独立物理领域中各自验证的线性关系放在一起，指出它们共享同一个变量 L 和同一种数学结构——因此可以用一个 LP 联立求解。**
