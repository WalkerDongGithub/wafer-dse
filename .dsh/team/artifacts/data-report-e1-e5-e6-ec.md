### G3 解析推导：B\*_joint = min(B\*_bump, B\*_therm)（证明要点）

> EvalDesigner 建议落盘（裁决后直接可用）。结论：当前模型（α_d = β_P = 0）下分离决策与联合模型**解析等价**，实测 11/11 一致（rel_diff=0.0000）是其直接验证。

**记号**（V5）：`L_e` = 链路 e 的扩展比（决策变量），`L*_e` = 包络下界（V5 §7.3，只依赖拓扑+路由+要求模型）；`λ_e` = lane 速率；`ppl_e` = 每 lane 功率；`d2l[d]` = die d 的链路集。

**模型结构**（build_scenario 实测）：
1. 性能：仅 `L_e ≥ L*_e`（无上界；V5 §7.5 对接——L 越大只收紧物理约束）。
2. bump（V5 §2(2c)+§4 C1）：每 die `B·Σ_{e∈d2l[d]} λ_e·L_e ≤ K_d`，`K_d` 在 α_d=0 下与 B 无关。
3. 热（V5 §2(2e)）：`G·T = P + b`，`P_d = P0_d + B·Σ_{e∈d2l[d]} ppl_e·L_e`，`T ≤ T_max` → 每 die `B·Σ ppl_e·L_e ≤ 常数`（线性）。
4. 几何：α_d=0 → die 面积与 B 无关 → 面积约束恒松（INSIGHT_READING"低 B 面积约束恒松"）。

**论证**：
1. 对固定 B，每条约束均随 L 单调增（bump/热 LHS ∝ L）。故可行集在 L 方向上的最优点 = `L = L*`：`(B, L*) 满足全部约束 ⟺ ∃L≥L* 满足`。因此联合可行 ⟺ 各因素在 L=L* 处独立可行。
2. 各因素对 B 的可行集均为向下闭区间 `[0, B*_factor]`（约束线性于 B，LP 精确可判，单调）。
3. 联合可行集 = 各区间交集 = `[0, min(B*_bump, B*_therm)]`（几何恒松，不参与）→ **B\*_joint = min(B\*_bump, B\*_therm)**。∎
4. 反例条件（何时出现分歧）：任一因素约束含**跨因素共享决策变量**（非仅标量 B）——C4/布线 lane 容量（G4）、分割比 ρ（G5）、或 die 缩放下面积与负载同含 B 但**预算与使用同向变化仍可分离**（EC 已实测零反转）。当前模型无此类交互。

**诚实边界**：本等价性是当前线性可分离模型的数学事实，不是缺陷——它把"耦合必要"的论证责任转移到：① 模型要素层（C4/ρ/真交互），或 ② 论文口径层（insight 4 主张"单一模型统一求解 + 全局最优"，不主张"分离会得出不同数字"）。
