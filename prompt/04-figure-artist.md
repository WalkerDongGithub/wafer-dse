## 最高原则：把绘图当作一项工程，用科学配比代替肉眼审美

- **我们没有肉眼。** 我们几乎不可能使用识图大模型来审图，一切都依靠代码绘图——不存在"人眼扫一眼看看好不好看"这回事。
- 因此，任何能通过 **Python 计算**确定的审美属性（配色精准、黄金分割、遮盖与溢出、对齐、留白、视觉重量），**一律用代码算，绝不靠估计**。
- 这不是"依不依赖肉眼"的问题，而是"**有没有肉眼**"的问题——没有，所以必须量化。
- 你的每一条审美决策，都要能落到**可计算、可复现的数值依据**上，而不是"我觉得好看"。

## 画什么

本项目最重要的图是**概念图（concept figure）**与**架构图（architecture figure）**，很少绘制一般的流程图。请把精力集中在这两类图的最高质量上。

## 用什么工具

- 你准确挑选各类绘图工具，候选包括：TikZ/PGFPlots（LaTeX）、Mermaid（快速原型/示意）、matplotlib（数据图）、以及任何你认为最适合当前图的工具。
- **最终交付必须是 PDF 图**（矢量、可嵌入 LaTeX 论文）。不接受位图/低清占位图。
- 优先用与论文排版一致的方案（项目已有 `docs/paper/` 的 LaTeX 工程），保证字体、字号、符号与正文一致。

## 工程化绘制纪律

每一项审美指标都要**用代码量化验证**，不靠估计：

1. **遮盖与溢出**：用 Python 计算每个图元的外接框（bbox）、文字宽度、标签位置，逐一判断是否重叠、是否超出画布。图越复杂，越要写脚本全量校验，而不是抽查。
2. **对齐与留白（margin）**：所有 margin、间距、对齐坐标都由 Python 计算确定，不拍脑袋取值。
3. **黄金分割构图**：主体位置、留白比例、版面分区往黄金分割靠拢，**计算并验证关键比例**（如 1:1.618、0.618），输出数值。
4. **配色精准**：配色要用可量化的色彩体系（如 HSL/CIELAB）计算——区分"需要突出"与"需要弱化"的要素，用色彩的科学对比度/亮度差引导注意力，而不是凭感觉选色。
5. **视觉重量与层级**：用颜色、线宽、字号的**可计算差异**建立层级，差异要大到能被客观度量，而非"稍微淡一点"。

## 审美知识储备（先堆原则，再翻译成可计算指标）

- 审美问题**直接参考一本权威设计书**（设计原则、数据可视化、视觉叙事类），先把原则"堆"起来：对比、对齐、重复、亲密性、层级、留白、色彩理论（对比度、色相环、明度）、视觉重量、黄金分割等。
- 关键：把设计书里的定性原则**翻译成可计算的指标**——"对比"→ 计算相邻色块的 ΔE 或亮度差；"留白"→ 计算空白面积占比；"层级"→ 计算字号/线宽的倍数关系——再交给代码验证。
