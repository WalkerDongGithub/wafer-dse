# 多角色协作 Prompt 库

本目录保存 wafer-dse（晶圆级交换机设计空间探索）项目由**不同 agent 分角色协作**时使用的角色设定（system prompt）。每个 `.md` 是一个**独立可用的角色 prompt**，可以直接整段粘贴给对应 agent。

角色之间通过 `memory/` 目录下的协作文件（请求/回复/报告）交接，**不共享上下文**。

## 全局硬约束：先读"道"，再做事（适用于所有角色）

每个角色在动手做任何事之前，**必须先读完以下两份文档**，并确保自己的产出与它们对齐：

1. **[notes/MATH_MODEL_V5_JOINT_SENSITIVITY.md](../notes/MATH_MODEL_V5_JOINT_SENSITIVITY.md)** —— V5 联合模型定稿。
   - 这是模型的唯一权威。任何与 V5 不一致的代码/论文/实验产出，**一律打回**。
   - V5 没提到的，不要自己加；V5 已删除的（同构简化、求解流程、灵敏度分析），**禁止复活**。

2. **[insight.md](../insight.md)** —— 项目"道"层面 critical insight 7 条。
   - 这是项目方法论的脊椎。任何产出（尤其是论文文字）**必须体现这 7 条设计之道**，不能写成"用了 LP 算 B\*"的技术流水账。
   - **论文撰写者（03b）特别纪律**：写任何一段论文文字前，必须自问"这段在体现 insight 1-7 的哪一条？"；如果一段文字不体现任何一条 insight，**删除重写**。

**为什么有这条硬约束**：项目最大的风险是"道"流失——insight 7 条是项目真正的方法论贡献，但如果不强制每个角色先读，agent 会朝"术的反客为主"漂移，把论文写成技术报告而非立场宣言。

## 协作机制（核心）

### 主从协作：03a 是唯一长期上下文

- **所有人都是 03a 的子 agent。** 03a 拥有完整的领域理解和连贯的会议安排；其余子 agent 是完成各自职责的"工具人"。
- **上下文保存性质（硬约束）**：03a 的上下文**长期保存**；子 agent 的上下文**可能不会长期保存**。因此所有结论、请求、解答、do 报告**必须落在 memory 文件里**，不能只留在对话里。这是主从（master-slave）协作的根基。

### Memory 目录约定

- 项目下有 `memory/` 目录，每个子 agent 有一个专属子目录 `memory/<agent-id>/`（如 `memory/01-code-engineer/`）。
- 向他人咨询/请求/质疑的协作文件，放在**对方的目录**下。
- 每个 agent 在自己目录下处理所有来自他人的请求，做出对应动作，完成后回复。
- **文件格式**：询问/回复遵循固定格式（询问精准、回复有据可循），见 [00-qna-protocol.md](./00-qna-protocol.md)。

### 一次 Meeting = 两个连贯阶段（由 03a 控制）

每次启动任务 = 一次 meeting。meeting 只有一个目标：让所有人都完成自己的 do。整个过程由 03a 主持并控制节奏，分两个**连贯**阶段：

**阶段一：Q&A（提问与解答）**

- 所有人可以向其他人发送**请求与质疑**（写在对方目录下）。
- 每个 agent 检查自己目录下的请求与质疑，做出解答或相应动作。
- **只有当所有人的质疑和请求都得到满足之后**，才进入下一阶段。Q&A 是循环的：解答可能引发新的质疑，直到收敛。
- 目的：降低思考难度——没必要为搞清某个问题就去死读别人负责的区域，有基础理解即可，实在不知道就在 Q&A 阶段询问或质疑。

**阶段二：Do（各自干活）**

- 所有人开始各自的工作。
- 每个 agent 在 do 结束后，**必须落实一份完整工作报告**到自己的 `memory/<agent-id>/do-<YYYYMMDD>-<主题>.md`：做了什么、哪些位置可靠、哪些位置还有问题但没做。
- **这是硬约束，不是可选项**：子 agent 的上下文是 stateless 的（对话结束即可能清空），产出若不落盘到 `memory/` 文件就会**彻底丢失**，下一次 meeting 从零开始。落盘是子 agent 产出的唯一持久化手段。
- 当**所有人的 do 阶段都结束**，本次 meeting 结束。

### Meeting 收尾：03a 汇总报告

meeting 结束后，03a 汇总所有人的工作，向项目负责人（用户）报告：

1. **我们做了哪些事**；
2. **某一个人的哪些问题、被谁、如何解决**；
3. **谁的问题似乎没有得到妥善解决**；
4. **03a 自己对本次结果的满意度评价**。
