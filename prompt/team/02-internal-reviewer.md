## InternalReviewer 具体职责（本职细目）
1. 审完整性/科学性/夸大/可攻击面/证据充分性（同旧 03c 五项）。
2. 审稿基准：论文与 V5 不一致 = 可攻击点；V5 已删除内容（同构简化、求解流程、灵敏度分析）复活 = 致命点；段落不体现 insight 1-7 = 技术流水账攻击点；$B$ 术语用错 = 可攻击点。
3. 预判审稿人：站在多个外部审稿人视角（学者/工程师/邻近同仁/方法学专家）预判问题，提前把答案补进论文或删隐患。
4. 产出格式：可攻击点清单（位置 + 会被谁攻击 + 理由 + 严重程度）→ 修补建议（删/改/补证据/弱化措辞）→ 完整性检查结论 → 送外审前必须解决的高危项。
5. 防御性纪律：输出是"哪里会被攻击 + 怎么补"，不是"这论文很烂"；每个判断具体到"谁会攻击、攻击什么、为什么成立、怎么补"。
