# UCIe 去加重 — $-2.2$ dB 到底在干什么

---

## 1. 滤波器的具体行为

$$V_{out}(n) = C_0 \cdot V_{in}(n) + C_{+1} \cdot V_{in}(n-1)$$

$$C_0 = 0.888, \quad C_{+1} = -0.112, \quad |C_0| + |C_{+1}| = 1$$

在两种极端输入模式下：

**模式 A — 连续同值**（$V_{in}(n) = V_{in}(n-1) = 1$）：

$$V_{out} = 0.888 \cdot 1 + (-0.112) \cdot 1 = 0.776$$

$$20 \log_{10}(0.776) = -2.2\text{ dB}$$

**模式 B — 持续翻转**（$V_{in}(n) = 1$，$V_{in}(n-1) = 0$）：

$$V_{out} = 0.888 \cdot 1 + (-0.112) \cdot 0 = 0.888$$

$$20 \log_{10}(0.888) \approx -1.0\text{ dB}$$

等一下——这个不对。翻转的增益不是 1。

---

## 2. 纠正 — 翻转模式也不等于 Nyquist

模式 B（$1 \to 0$）是**单次翻转**——不是 Nyquist 频率。Nyquist 频率是**持续交替** $1, 0, 1, 0, 1, 0, \dots$。

Nyquist 频率下的稳态输入：$V_{in}(n) = 1$，$V_{in}(n-1) = 0 \to$ 这和模式 B 一样。但稳态翻转下，当前 bit = 1 时前一个 bit = 0 → 模式 B **确实就是 Nyquist 下的输入状态**。

但注意每个 bit 都有前一个 bit。在稳态 $101010\dots$ 中，当前 $=1$ 时前一个 $=0$：

$$V_{out} = 0.888 \cdot 1 + (-0.112) \cdot 0 = 0.888$$

这不是 1.0。那么 $-2.2$ dB 的去加重在 Nyquist 处不是 0 dB？

---

## 3. 再纠正 — 准确算频域幅度

FIR 滤波器：

$$H(z) = C_0 + C_{+1} z^{-1}, \quad z = e^{j\omega UI}$$

$$H(f) = C_0 + C_{+1} e^{-j 2\pi f \cdot UI}$$

DC（$f = 0$）：$e^{-j0} = 1$

$$H(0) = 0.888 - 0.112 = 0.776, \quad 20\log_{10}(0.776) = -2.2\text{ dB}$$

Nyquist（$f = f_N = \frac{1}{2 \cdot UI}$）：$e^{-j\pi} = -1$

$$H(f_N) = 0.888 + 0.112 = 1.000, \quad 20\log_{10}(1.000) = 0.0\text{ dB}$$

---

**所以确切的含义是**：

- DC 处（$f = 0$）：输出幅度是输入的 0.776 倍 → **$-2.2$ dB**
- Nyquist 处（$f = f_N$）：输出幅度是输入的 1.0 倍 → **$0$ dB**

去加重在 Nyquist 频率处**完全不衰减**——全功率通过。在 DC 处衰减 2.2 dB。**高频比低频多了 2.2 dB 的相对增益。**

---

## 4. 这个 2.2 dB 干了什么

信道的衰减曲线 $\alpha(f)L$（dB）在从 DC 升到 $f_N$ 的过程中上升了一些量——设为 $\Delta$ dB。

去加重把 DC 处额外压低了 2.2 dB，让 DC 和 $f_N$ 之间的相对差从 $\Delta$ 缩小到 $|\Delta - 2.2|$。

### 案例 1：信道不平恰好 2.2 dB

$$\alpha(f_N)L\text{ (Nyquist)} - \alpha(0)L\text{ (DC)} = 2.2\text{ dB}$$

无均衡时：DC 不衰减，Nyquist 衰减 2.2 dB。$\Delta G = 2.2\text{ dB}$。

有去加重时：
- DC：信道 0 dB + 去加重 $-2.2$ dB = $-2.2$ dB
- Nyquist：信道 $-2.2$ dB + 去加重 0 dB = $-2.2$ dB

$$\Delta G = 0\text{ dB} \quad\checkmark\quad\text{完全平坦}$$

**这就是去加重被设计成恰好 2.2 dB 的目的——它假设 UCIe 信道的 $\alpha(f_N)L - \alpha(0)L$ 就在 2.2 dB 附近。**

---

### 案例 2：信道不平恰好 4 dB

无均衡时：DC 不衰减，Nyquist 衰减 4 dB。$\Delta G = 4\text{ dB}$。

有去加重（$-2.2$ dB）时：
- DC：0 − 2.2 = $-2.2$ dB
- Nyquist：−4 + 0 = $-4$ dB

$$\Delta G = |-4 - (-2.2)| = 1.8\text{ dB}$$

不平从 4 dB 缩小到 1.8 dB。**补偿不完全，但改进了 55%。**

---

### 案例 3：信道不平恰好 1 dB

DC 不衰减，Nyquist 衰减 1 dB。$\Delta G = 1\text{ dB}$。

有去加重时：DC = $-2.2$ dB，Nyquist = $-1$ dB。$\Delta G = 1.2\text{ dB}$。

**过量补偿——去加重比信道不平还大，把综合响应搞得更不平了。这时候应该选 Setting 1（0 dB，关掉去加重）。**

---

## 5. 所以 UCIe 只给两个 setting 就够了

| 信道不平 $\Delta$ | 选哪个 setting | 效果 |
|:---:|:---:|------|
| $\Delta < 1.1\text{ dB}$ | Setting 1（0 dB） | 不开去加重——信道本身已经很平 |
| $\Delta > 1.1\text{ dB}$ | Setting 2（−2.2 dB） | 开去加重——把不平缩小 |

**训练期间两个都试，哪个 setting 的眼图更大就用哪个。** 不需要 20 个精细的预设值——因为 UCIe 信道的变化范围很窄（2mm–25mm，两种介质类型，$\Delta$ 不会从 0 跳到 10 dB）。

---

## 6. 整体图景

```
Signal Spectrum:  低频 ████████████  高频 ████        ← 发送器输出（去加重压低频）
Channel:          低频 -0.5 dB       高频 -2.7 dB     ← 信道吃掉更多高频
Received:         低频 ████████████  高频 ████        ← 接收端高低频大致均匀
                                            ↑
                                   残余不平 ~0 dB（如果匹配好）
```

**去加重不改变高频——它只压低低频。压低的量恰好弥补信道对高频的额外衰减。整个链路从 DC 到 $f_N$ 的通带变得平坦。**
