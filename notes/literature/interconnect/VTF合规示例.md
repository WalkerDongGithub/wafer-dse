# VTF 合规 — 怎么看 UCIe Table 5-11

---

## 1. 场景

Advanced Package，32 GT/s。

Nyquist 频率 $f_N = 16\text{ GHz}$。

查 UCIe Table 5-11（p201）：

| 参数 | 约束 |
|------|------|
| 损耗 | $IL(f_N) > -5\text{ dB}$ |
| 串扰 | $XT(f_N) < 1.5 \cdot IL(f_N) - 19$ $\land$ $XT(f_N) < -24\text{ dB}$ |

---

## 2. 损耗掩模 — 画出来是一条线

掩模是一根从 $(0, 0)$ 到 $(f_N, IL(f_N))$ 的**直线**：

$$IL_{\text{mask}}(f) = \frac{f}{f_N} \cdot IL(f_N)$$

取 $IL(f_N) = -5\text{ dB}$（合规的上限）：

$$IL_{\text{mask}}(f) = -5 \cdot \frac{f}{16\text{ GHz}}\text{ dB}$$

| 频率 | 掩模值 |
|:----:|:------:|
| 0 GHz | 0 dB |
| 4 GHz | −1.25 dB |
| 8 GHz | −2.5 dB |
| 12 GHz | −3.75 dB |
| 16 GHz | −5 dB |

**合规条件**：实际测量的 $IL(f)$ 必须**在这条线以上**（损耗不能超过它）。

---

## 3. 三个通道 — 谁能过

```
频率 →     0      4      8      12     16 GHz
掩模线：   0    -1.25   -2.5   -3.75   -5   dB

通道 A：   0     -0.5   -1.0    -2.0   -3.5  dB   ← 全部在线上方 ✓ 合规
通道 B：   0     -1.5   -3.0    -5.0   -6.0  dB   ← 16GHz处超标 ✗
通道 C：   0     -0.8   -4.0    -3.0   -4.0  dB   ← 8GHz处有坑 ✗
```

通道 C 的 16 GHz 损耗是 −4 dB > −5 dB → Nyquist 频率本身通过了。**但 8 GHz 处有一个 −4 dB 的谐振坑**——掩模要求 8 GHz 处不差于 −2.5 dB，它是 −4 dB → **不合规。**

**这就是线性掩模的威力。** 它抓住了通道 C 的阻抗不连续问题——某个中间频率的反射谐振吞掉了信号。虽然 $f_N$ 处看起来还行，但通道质量不均匀。

---

## 4. 串扰掩模 — 分两步看

### 第一步：计算损耗掩模下的串扰上限

取 $IL(f_N) = -4\text{ dB}$（Nyquist 处实测损耗）：

$$XT_{\text{max from IL}} = 1.5 \cdot (-4) - 19 = -25\text{ dB}$$

$$XT_{\text{absolute cap}} = -24\text{ dB}$$

**取更严格的**：$\min(-25, -24) = -25\text{ dB}$

所以串扰必须 **< −25 dB**。

### 第二步：不同损耗对应不同的串扰上限

| $IL(f_N)$ | $XT$ 上限 | 解释 |
|:---:|:---:|------|
| −1 dB | −23 dB（绝对上限主导） | 损耗很小 → 信号强 → 允许串扰 −23 dB |
| −3 dB | −23.5 dB（接近） | |
| −4 dB | −25 dB（IL 公式主导） | 损耗较大 → 信号弱 → 串扰必须更低 |
| −5 dB | −26.5 dB（IL 公式主导） | 损耗大 → 信号很弱 → 串扰必须极低 |

**联合约束的直觉**：信号越弱（损耗大），它对串扰越敏感，所以串扰上限就越严格。

---

## 5. 一个完整的合规检查流程

假设一条 Advanced Package 走线，目标 32 GT/s：

**Step 1**：测 $IL(f)$ 和 $XT(f)$（仿真或实测）。

**Step 2**：检查损耗。

- $IL(16\text{ GHz}) = -3.8\text{ dB}$。要求 > −5 dB ✓
- 全频段 $IL(f)$ 在直线 $(f/16\text{GHz}) \cdot (-5)$ 以上 ✓

**Step 3**：检查串扰。

- $IL(16\text{ GHz}) = -3.8\text{ dB}$
- 串扰上限 $= \min(1.5\cdot(-3.8) - 19,\; -24) = \min(-24.7,\; -24) = -24.7\text{ dB}$
- 实测 $XT(16\text{ GHz}) = -28\text{ dB} < -24.7\text{ dB}$ ✓
- 全频段 $XT(f)$ 在线性掩模以下 ✓

**Step 4**：两条掩模都通过 → **通道合规。**

---

## 6. 这个示例里 2mm 走线能不能过？

我们之前计算的 Advanced Package 2mm 走线：$\alpha \approx 0.02\text{ Np/mm}$。

$$IL(16\text{ GHz}) = -8.686 \cdot 0.02 \cdot 2 = -0.35\text{ dB}$$

要求 > −5 dB。**余量极大——2mm 走线的损耗远远低于合规上限。** 这也是为什么 Advanced Package 可以无接收端端接、只需要 −2.2 dB 去加重、不需要 CTLE/DFE——通道本身几乎不衰减。

如果是 25mm Standard Package，$\alpha \approx 0.04\text{ Np/mm}$（有机基板 Df 更高）：

$$IL(16\text{ GHz}) = -8.686 \cdot 0.04 \cdot 25 = -8.7\text{ dB}$$

**超标了。** 所以 25mm 走线只能在 16 GT/s 以下跑——32 GT/s 需要更短的距离或更好的介质材料。
