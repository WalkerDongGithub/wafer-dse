## 0. B* 的语义与 sensitivity 的叙事

**B\* = f(期待, 约束)**。我们「尽我们所能」，在给定「期待」和「约束」下求最大端口无阻塞带宽。不强调整体乐观/悲观——说乐观总有更乐观的估计，说悲观总有更现实的约束。

- **期待（性能侧）**：无阻塞目标——要求最坏流量模式（排列）下都无阻塞；决策用最优自适应路由（min ΣL），最少留多少 L 才有希望达到无阻塞。合起来 = 需求下界。
- **约束（物理侧）**：bump 预算、热（芯片峰值功耗 + PHY 额定功耗）、布线、C4；信号完整性通过规范文档（UCIe/OIF-CEI 的 lane rate/reach/BER/功耗档位）内嵌为约束。

**提高 B\* 的两条路（sensitivity 的两个旋钮）**：
1. 约束放宽：工艺制程、散热手段、功耗调度（不跑峰值）→ B\* 提高。
2. 期待降低：不要求时刻无阻塞，只在经典场景（all-reduce）无阻塞、其他流量（all-to-all）降级 → L 包络变小 → B\* 提高。

**sensitivity 的本质**：刻画 B\* 对「期待」和「约束」两个维度的响应。期待降低 或 约束放宽，B\* 都提高；反之亦然。§8 的 ∂B\*/∂θ 里，θ 覆盖「约束旋钮」（物理参数 p/η/R/α_d/β_P）与「期待旋钮」（无阻塞要求严格程度——要求哪些流量模式进 R 集合）。

## 1. 目标：带宽影子价格 ∂B*/∂b_i

sensitivity 的本质不是「哪个约束 binding」，而是「B* 对约束 rhs 的梯度」：

```
∂B*/∂b_i = 约束 i 的 rhs 松弛 1 单位，B* 增加多少
```

这是架构师真正想要的：投资哪个约束（+1 bump / +1 W / +1 lane）换多少带宽。

## 2. 数学形式：KKT / 包络定理

把 B* 定义为参数化优化的最优值：

```
B*(b) = max_{B, L∈F}  B   s.t.  B·(A_i·L) ≤ b_i,  ∀i
```

其中 F 是性能侧（路由 + 定义式）决定的 L 可行域（与 b 无关）。

拉格朗日：`L = B + Σ_i λ_i (b_i − B·(A_i·L))`

**包络定理**：∂B*/∂b_i = λ_i*（约束 i 的 KKT 乘子 = 带宽影子价格）。

KKT 条件（对 B 求偏导）：

```
1 − Σ_i λ_i (A_i·L*) = 0   ⟹   Σ_i λ_i (A_i·L*) = 1
```

互补松弛：λ_i ≥ 0，λ_i (b_i − B*·(A_i·L*)) = 0。

### 2.1 框架严谨性（非凸问题的处理）

注意 `B·(A_i·L)` 是双线性项，`max_{B,L} B s.t. B·(A_i·L)≤b_i` 是**非凸**问题——KKT 只是驻点必要条件，不保证全局最优。

**因此 B\* 不通过求解上述 max 问题得到**，而是按 V4 §6 用「固定 B 的可行性 LP + 二分搜索」求（每次固定 B，约束是 L 的线性不等式，是凸 LP；B\* 的全局性由「可行性关于 B 单调 + 二分」保证，不依赖 KKT）。

λ 的取得是**事后闭式**：二分收敛后取最后一次可行解 L\*，对每个绑定约束 j 用 λ_j = 1/(A_j·L\*)（因 B\* = b_j/(A_j·L\*) 在绑定处刻画同一超平面）。该闭式值与 max-B 问题在 B\* 处的 KKT 乘子数值一致，但**不依赖**求解非凸 max 问题。

§8 的 ∂B\*/∂θ = Σλ_i ∂g_i/∂θ 挂 **Milgrom–Segal (2002) envelope theorem**：只要求 value function 在参数处可微 + 约束规范，**不要求凸性**。在 B\* 可微点成立；两个约束同时绑定的退化点只给方向导数/次梯度（见 §4）。

## 3. 单约束绑定：闭式解

若仅约束 j 绑定（其余 slack → λ_i = 0）：

```
λ_j = 1/(A_j·L*)   ⟹   ∂B*/∂b_j = 1/(A_j·L*)
```

物理含义：A_j·L* 是「约束 j 单位带宽的 lhs 占用」，其倒数是「每松弛 1 单位 rhs 换多少 Gbps」。

## 4. 多约束绑定：KKT 系统（退化情况）

若约束集 J 同时绑定：`{λ_j ≥ 0, Σ_{j∈J} λ_j (A_j·L*) = 1}`。单独松弛一个约束 B* 不增（其余仍挡路），λ_j 需联合确定（退化，不唯一）。此时「先改哪个」由绑定演化序列（沿 B 轴谁先绑定）回答。

## 5. 与「固定 B feasibility 的 duals」的区别（实现注记）

- 目标量 ∂B*/∂b_i = λ_i* 是 **max B 优化问题**的 KKT 乘子。
- V4 二分搜索每次是「固定 B 的可行性判定」，无目标函数，其 duals 不可靠（test08）。
- 二者**不是同一个量**：feasibility 的 duals = ∂(min ΣL)/∂b_i（固定 B 下），≠ ∂B*/∂b_i。
- 实现上：二分得 B* 和 L* 后，直接用闭式 λ_j = 1/(A_j·L*) 或 KKT 系统求 λ，**不依赖 feasibility 的 duals**。

## 6. 归一化与可比性

不同约束 rhs 单位不同（bump 数 / W / lane 数），归一化后给架构师：每 +1 μbump → X Gbps；每 +1 W 散热 → Y Gbps；比值 = 投资优先级（例：ν_bump/ν_thermal 判断投 bump pitch 缩减还是更激进冷却）。

## 8. §2.8 下的 sensitivity：物理参数梯度

§2.8 接入后，约束 rhs 本身是 B 的函数（N_total(B)、P_peak(B)），「b_i 独立于 B」的前提失效。更本质的 sensitivity 目标是对**物理参数** θ 求导：

```
∂B*/∂θ = Σ_i λ_i* · (∂g_i/∂θ)
```

其中 g_i(B, L, θ) ≤ 0 是约束 i，λ_i* 是 KKT 乘子（单约束闭式 1/(A_j·L*)），∂g_i/∂θ 是约束对参数的显式偏导。

统一两种情况：
- θ = rhs 常数 b_i → ∂g_i/∂b_i = 1 → ∂B*/∂b_i = λ_i（回到 §2）
- θ = 物理参数（bump pitch p、利用率 η、die 边长 d_0、缩放斜率 α_d、功耗斜率 β_P、热阻 R）→ 上式通用形式

物理参数清单（§2.8 引入 α_d、β_P、d_0；§2.3–2.6 引入 p、η、R 等）。每个 ∂g_i/∂θ 都是对 V4 §4 线性化系数的显式求导。
