# 模型 ↔ 现实真实性 gap 盘点（草案 v1）

> 目标：回答「模型假设离现实多远、哪些需补、哪些做不了」。
> 原则（项目负责人定）：B\* = f(期待, 约束)，尽我们所能；不强调乐观/悲观。SI 靠规范文档内嵌；热用峰值功耗 + PHY 额定功耗。
> 状态：草案 v1（吸收 2026-08-17 修正）。

## 一、约束怎么来（B\* = f(期待, 约束) 的「约束」侧）

- **期待（性能侧）**：无阻塞目标。
- **约束（物理侧）**：
  - bump 预算、布线、C4。
  - 热 = 芯片峰值功耗 + PHY 额定功耗（够用，不讨论翘曲/PDN 瞬态/瞬态热）。
  - SI = 靠规范文档内嵌（对齐 UCIe/OIF-CEI，lane rate/reach/BER/功耗档位已框死 SI）。技术选型必须依赖已有互连标准。

## 二、假设逐条评估（内部风险标记，论文措辞用「期待/约束」）

| 假设 | 风险方向 | 说明 |
|------|---------|------|
| 最坏情况稳态 | 保守 | 持续峰值温度上界 |
| gap=0（网格紧贴） | 轻微乐观 | die 间缝隙略高估热传导 |
| 布局固定 | 可接受 | 布局是外层选型 |
| 集总 R_vert | 保守 | 已升级三层热阻（8/75/50-80） |
| S_n 共轭类 | 保守（术） | 非核心 idea |
| on-die 零代价 | 乐观（高估 B\*） | die 内链路功耗/面积未计入 |
| 套娃热 | 乐观（低估温度） | 丢组内温度梯度 |

## 三、明确不讨论的（约定范围，论文如实声明边界）

- 翘曲 / 机械应力（V4 已移出）。
- PDN 启动瞬态。
- 瞬态热（只做稳态）。
- 良率 / 容错。
- 时钟同步。

这些不是「做不了所以要交代」的负担，而是「我们约定只讨论这一块」的边界声明。

## 四、待补 / 待核实

- on-die 零代价 和 套娃热 的修补（补保守项 vs 声明上界语义）。
- SI 内嵌的完整性（规范文档覆盖了哪些 SI 维度，是否还有规范没框死的 SI 因素）。
