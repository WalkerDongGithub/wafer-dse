# 为什么特性阻抗变化必然产生反射

---

## 1. 问题陈述

一根传输线，左边 $Z_{01}$，右边 $Z_{02}$。一个正向波从左边入射到交界面上。

**已知**：在交界面处，

- 电压不能突变（基尔霍夫电压定律 — 导线是连续的）
- 电流不能突变（基尔霍夫电流定律 — 电荷不会凭空堆积）

**问**：既然电压和电流都必须连续，为什么波形不能无缝地进入右边，而非得产生一个反向波（反射）？

---

## 2. 约束冲突 — 为什么不能只有入射波

设交界面在 $x = 0$。左边 $Z_{01}$，右边 $Z_{02}$。

**约束 1** — 电压连续（交界面两边电压相等）：

$$V_{\text{left}}(0) = V_{\text{right}}(0)$$

**约束 2** — 电流连续（交界面两边电流相等）：

$$I_{\text{left}}(0) = I_{\text{right}}(0)$$

**约束 3** — 左右两边的 $V/I$ 关系：

在左边，电压和电流的比值必须满足：

$$\frac{V_{\text{left}}}{I_{\text{left}}} = Z_{\text{left, total}}$$

在右边，对于进入 $Z_{02}$ 的波的电压和电流部分：

$$\frac{V_{\text{right}}}{I_{\text{right}}} = Z_{02}$$

**冲突**：设左边只有一个入射波（$V_+$，$V_- = 0$）。此时 $V_{\text{left}}/I_{\text{left}} = Z_{01}$。

如果 $Z_{01} \neq Z_{02}$，则左边的 $V/I = Z_{01}$，右边要求 $V/I = Z_{02}$。**同一个电压-电流对不能满足两个不同的比值。**

但约束 1 和约束 2 要求 $V$ 和 $I$ 在交界面连续。矛盾。

**结论：纯入射波不能独自满足交界面条件。必须存在一个额外的波来调节比值。**

---

## 3. 反射波怎么解决冲突

在左边同时存在入射波和反射波：

$$V_{\text{left}} = V_+ + V_-$$
$$I_{\text{left}} = \frac{V_+}{Z_{01}} - \frac{V_-}{Z_{01}}$$

（反射波电流的负号：因为反射波沿 $-x$ 传播，电流方向与正向波相反）

在右边只有透射波：

$$V_{\text{right}} = V_T$$
$$I_{\text{right}} = \frac{V_T}{Z_{02}}$$

应用约束 1 和约束 2：

$$V_+ + V_- = V_T \tag{电压连续}$$

$$\frac{V_+}{Z_{01}} - \frac{V_-}{Z_{01}} = \frac{V_T}{Z_{02}} \tag{电流连续}$$

两个方程，两个未知数（$V_-, V_T$）。解之：

从第一个方程：$V_T = V_+ + V_-$

代入第二个方程：

$$\frac{V_+ - V_-}{Z_{01}} = \frac{V_+ + V_-}{Z_{02}}$$

交叉相乘：

$$Z_{02}(V_+ - V_-) = Z_{01}(V_+ + V_-)$$

$$V_+(Z_{02} - Z_{01}) = V_-(Z_{01} + Z_{02})$$

$$\frac{V_-}{V_+} = \frac{Z_{02} - Z_{01}}{Z_{01} + Z_{02}}$$

**即：**

$$\boxed{\Gamma = \frac{V_{\text{reflected}}}{V_{\text{incident}}} = \frac{Z_{02} - Z_{01}}{Z_{01} + Z_{02}}}$$

---

## 4. 三个特殊情况 — 用约束冲突解释

### 情况 A：$Z_{01} = Z_{02}$

$$\Gamma = 0, \quad V_T = V_+, \quad V_- = 0$$

左边 $V_+/I_+ = Z_{01}$。右边要求 $V_T/I_T = Z_{02} = Z_{01}$。两个比值相等 → 入射波已经满足右边对 $V/I$ 的约束 → 不需要反射波。

**入射波直接进入右边，无能量反射。交界面"消失了"。**

---

### 情况 B：$Z_{02} \to \infty$（开路）

$$\Gamma = +1, \quad V_- = V_+, \quad V_T = 2V_+$$

右边要求 $V/I = \infty$，即 $I = 0$，零电流。反射波必须产生恰好 $-I_+$ 的电流来抵消入射波的电流，使交界面的总电流为零。

反射波电流为 $-V_-/Z_{01} = -V_+/Z_{01} = -I_+$。恰好抵消入射波电流 $I_+$。**交界面满足 $I=0$（开路条件）。电压加倍为 $V_+ + V_- = 2V_+$。**

---

### 情况 C：$Z_{02} \to 0$（短路）

$$\Gamma = -1, \quad V_- = -V_+, \quad V_T = 0$$

右边要求 $V = 0$。反射波必须产生恰好 $-V_+$ 的电压来抵消入射波电压，使交界面的总电压为零。

反射波电压为 $-V_+$，交界面总电压为零。**电流加倍：$I_{\text{left}} = V_+/Z_{01} - (-V_+)/Z_{01} = 2V_+/Z_{01}$。**

---

## 5. 物理直觉：$V/I$ 比值必须处处自洽

核心认知：

$$V(x) = V_+ e^{-\gamma x} + V_- e^{+\gamma x}$$

$$I(x) = \frac{V_+ e^{-\gamma x} - V_- e^{+\gamma x}}{Z_0}$$

**单根均匀传输线上，$V(x)$ 和 $I(x)$ 有两个自由度（$V_+$ 和 $V_-$）。** 这两个自由度用来满足**两个**边界条件——发送端一个、接收端一个。

在 $Z_0$ 变化处，每一侧都有两个自由度。交界面上的电压连续和电流连续给出了**两个方程**，把入射波、反射波、透射波联系起来。**两个方程能解两个未知数——解出来的正是 $\Gamma$ 和 $V_T$。**

---

## 6. 回到 UCIe：驱动器阻抗为什么必须匹配走线的 $Z_0$

发送器输出阻抗 $Z_S$ 就是交界面左边的 $Z_{01}$。走线特性阻抗是右边的 $Z_{02}$。

如果 $Z_S = Z_0$：

$$\Gamma = 0$$

信号从发送器进入走线时，**没有反射产生。** 全部信号功率进入走线。

如果 $Z_S \neq Z_0$：

$$\Gamma \neq 0$$

一部分信号在发送端就被反射回来。更糟的是——这个反射波再次碰到发送器时，如果发送器也不匹配，会再次反射回走线。**两次反射的叠加产生 ringing。**

接收端同理：$Z_L \neq Z_0$ → 反射波回到走线 → 干扰后续比特。

---

## 7. 总结

**反射不是因为"阻抗变化"本身——反射是因为电压连续 + 电流连续 + 两边的 $V/I$ 比值不同——这三个约束不可能同时被单一入射波满足。必须存在一个额外的波（反射波）来调节交界面处的电压和电流，使得三个约束同时成立。**
