# 弹性力学 — 频域分析

---

## 一、进入频域

时域波动方程（无损）：

$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad c = \sqrt{\frac{E}{\rho}}$$

对 $t$ 做傅里叶变换（$u(x,t) \to U(x,\omega)$，$\partial/\partial t \to j\omega$）：

$$-\omega^2 U(x,\omega) = c^2 \frac{d^2 U(x,\omega)}{dx^2}$$

$$\boxed{\frac{d^2 U}{dx^2} + k^2 U = 0}, \quad k = \frac{\omega}{c}$$

这就是频域的空间 ODE。**和传输线的 $\frac{d^2V}{dx^2} = \gamma^2 V$ 形式完全一样，其中 $\gamma^2 = -k^2$。** 无损时 $k$ 是纯实数 → $\gamma = jk$ 是纯虚数 → 波只有相位旋转，无衰减。

---

## 二、通解

$$U(x,\omega) = U_+ e^{-jkx} + U_- e^{+jkx}$$

$$= U_+ e^{-j\frac{\omega}{c}x} + U_- e^{+j\frac{\omega}{c}x}$$

- $U_+ e^{-jkx}$：正向传播波（沿 $+x$）
- $U_- e^{+jkx}$：反向传播波（沿 $-x$）
- 两个待定常数 $U_+(\omega), U_-(\omega)$ 由**边界条件**确定——一个频率一个频率地定

时域解（逆傅里叶变换）：

$$u(x,t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} \left[U_+(\omega) e^{-j\frac{\omega}{c}x} + U_-(\omega) e^{+j\frac{\omega}{c}x}\right] e^{j\omega t} d\omega$$

---

## 三、力学阻抗 — 频域里最核心的量

和传输线的 $Z_0 = V/I$ 对应，定义**力学阻抗**：

$$Z_m(\omega) = \frac{\Sigma(x,\omega)}{V(x,\omega)}$$

其中 $\Sigma$ = 应力的傅里叶变换，$V = j\omega U$ = 粒子速度的傅里叶变换。

### 纯正向波

设 $U(x) = U_+ e^{-jkx}$（$U_- = 0$）：

$$\Sigma = E \cdot \frac{dU}{dx} = E \cdot (-jk) \cdot U_+ e^{-jkx} = -jEk \cdot U$$

$$V = j\omega \cdot U_+ e^{-jkx} = j\omega \cdot U$$

$$Z_m = \frac{\Sigma}{V} = \frac{-jEk}{j\omega} = -\frac{Ek}{\omega} = -\frac{E \cdot \omega/c}{\omega} = -\frac{E}{c}$$

取绝对值（方向约定统一处理）：

$$\boxed{Z_m = \frac{E}{c} = \sqrt{\rho E} = \rho c}$$

| 材料 | $\rho$ (kg/m³) | $E$ (GPa) | $c$ (m/s) | $Z_m$ (Pa·s/m) |
|------|:---:|:---:|:---:|:---:|
| 钢 | 7800 | 200 | ~5064 | ~$3.95 \times 10^7$ |
| 铝 | 2700 | 70 | ~5092 | ~$1.38 \times 10^7$ |
| 铜 | 8960 | 110 | ~3500 | ~$3.14 \times 10^7$ |
| 水 | 1000 | — | 1480 | $1.48 \times 10^6$ |
| 空气 | 1.2 | — | 343 | ~410 |

**$Z_m$ 在频域里是无损时的实数常数——和频率无关。** 给定应力波幅度，粒子速度 = 应力 / $Z_m$。给定粒子速度，应力 = 速度 × $Z_m$。

## 四、有损情况 — 复波数 $k^*$

### 4.1 修正本构关系

损耗来自本构。从 $\sigma = E\varepsilon$ 扩展为：

$$\sigma = E\varepsilon + \eta \cdot \frac{\partial\varepsilon}{\partial t}$$

频域中（$\partial/\partial t \to j\omega$）：

$$\Sigma = E\mathcal{E} + \eta \cdot j\omega\mathcal{E} = (E + j\omega\eta)\mathcal{E}$$

定义**复模量**：

$$\boxed{E^*(\omega) = E + j\omega\eta}$$

### 4.2 复波动方程

$\Sigma = E^* \frac{dU}{dx}$。代入动力学方程 $\frac{d\Sigma}{dx} = -\rho\omega^2 U$：

$$\frac{d}{dx}\!\left(E^* \frac{dU}{dx}\right) = -\rho\omega^2 U$$

$$\frac{d^2U}{dx^2} + \frac{\rho\omega^2}{E^*} U = 0$$

$$\boxed{\frac{d^2U}{dx^2} + k^{*2} U = 0}, \quad k^*(\omega) = \omega\sqrt{\frac{\rho}{E + j\omega\eta}}$$

### 4.3 复波数的分解

$$k^* = \beta - j\alpha$$

$$U(x) = U_+ e^{-jk^* x} = U_+ e^{-j\beta x} \cdot e^{-\alpha x}$$

- $\beta(\omega)$：空间频率（相位常数），波长 $\lambda = 2\pi/\beta$
- $\alpha(\omega)$：空间衰减率（Np/m），每 $1/\alpha$ 米后幅度降至 $1/e$

弱阻尼近似（$\eta\omega \ll E$）：

$$k^* \approx \frac{\omega}{c}\left(1 - j\frac{\eta\omega}{2E}\right)$$

$$\boxed{\beta \approx \frac{\omega}{c}, \quad \alpha \approx \frac{\eta\omega^2}{2\rho c^3}}$$

**$\alpha \propto \omega^2$（Kelvin-Voigt 模型下）。** 高频比低频衰减得快得多。敲杆时清脆的金属声（高频）先消失，沉闷的余音（低频）持续更久。

---

## 五、不同阻尼模型的频域对应

Kelvin-Voigt 只是最简单的一种。频域里不同阻尼模型对应不同的 $E^*(\omega)$ 和 $k^*(\omega)$：

| 阻尼模型 | 复模量 $E^*(\omega)$ | $\alpha(\omega)$ | 适用材料 |
|---------|--------------------|:---:|------|
| 无阻尼 | $E$ | 0 | — |
| Kelvin-Voigt | $E + j\omega\eta$ | $\propto \omega^2$ | 橡胶、聚合物 |
| 滞弹性（结构阻尼） | $E(1 + j\gamma)$ | $\propto \omega$ | 金属、混凝土 |
| 广义 Maxwell | $E_\infty + \sum_i \frac{E_i}{1+j\omega\tau_i}$ | 分段变化 | 精确建模 |

### 滞弹性模型要点

复模量 $E^* = E(1 + j\gamma)$，$\gamma$ 是损耗因子（和频率几乎无关）。

$$k^* = \frac{\omega}{\sqrt{E(1+j\gamma)/\rho}} \approx \frac{\omega}{c}\left(1 - j\frac{\gamma}{2}\right)$$

$$\alpha \approx \frac{\gamma\omega}{2c} \propto \omega$$

**每个振动周期耗散的能量比例恒定。** 高频时每秒振动次数多 → 每秒耗散更多 → 衰减更快——不是因为阻尼力大，而是因为振动频繁。

### 对比

| | Kelvin-Voigt | 滞弹性 |
|---|---|---|
| 阻尼力正比于 | 应变速率 $\partial\varepsilon/\partial t$ | 应变 $\varepsilon$（但相位滞后） |
| 每周期耗能 | $\propto \omega$（频率越高耗越多） | **常数**（和频率无关） |
| $\alpha(\omega)$ | $\propto \omega^2$ | $\propto \omega$ |
| 时域可否直接写 | ✓ 可以（$\eta\dot{\varepsilon}$） | ✗ 只能频域写（对应希尔伯特变换，非局域） |

**这和传输线里选 $R = R_{DC} + k_1\sqrt{f}$、$G = \omega C\tan\delta$ 来拟合不同频段的损耗行为完全一个道理。** 选什么阻尼模型取决于你在哪个频率范围分析什么材料。

## 六、频域力学阻抗（有损时）

有损时：

$$\boxed{Z_m^*(\omega) = \frac{\Sigma}{V} = \sqrt{\rho E^*(\omega)} = \sqrt{\rho(E + j\omega\eta)}}$$

有损时 $Z_m^*$ 是**复数量**——应力和粒子速度不再完全同相：

- 实部：有效力学阻抗（弹性储能为主）
- 虚部：相位滞后（能量耗散）

**这和你传输线里的 $Z_0 = \sqrt{(R+j\omega L)/(G+j\omega C)}$ 在 $R,G \neq 0$ 时变成复数完全一样。**

## 七、界面反射 — 频域视角

### 7.1 两种材料交界面

材料 1（$E_1^*, \rho_1$）和材料 2（$E_2^*, \rho_2$）在 $x = 0$ 处粘接。

$$Z_{m1}^* = \sqrt{\rho_1 E_1^*}, \quad Z_{m2}^* = \sqrt{\rho_2 E_2^*}$$

入射波从材料 1 来：$U_i e^{-jk_1 x}$。通解：

$$U_1(x) = U_i e^{-jk_1 x} + U_r e^{+jk_1 x}$$

$$U_2(x) = U_t e^{-jk_2 x}$$

交界面条件：**位移连续**（$U_1(0) = U_2(0)$），**应力连续**（$\Sigma_1(0) = \Sigma_2(0)$）。

$$U_i + U_r = U_t$$

$$E_1^*(-jk_1 U_i + jk_1 U_r) = E_2^*(-jk_2 U_t)$$

用 $Z_{m1}^* = E_1^*k_1/\omega$，$Z_{m2}^* = E_2^*k_2/\omega$ 化简：

$$\boxed{\Gamma(\omega) = \frac{U_r}{U_i} = \frac{Z_{m2}^* - Z_{m1}^*}{Z_{m2}^* + Z_{m1}^*}}$$

$$\boxed{T(\omega) = \frac{U_t}{U_i} = \frac{2Z_{m2}^*}{Z_{m2}^* + Z_{m1}^*}}$$

**和传输线的 $\Gamma = (Z_L - Z_0)/(Z_L + Z_0)$ 完全一样。** $Z_{m1}, Z_{m2}$ 分别来自两种材料——被除去的不是负载阻抗，是第二种材料的特征阻抗。

### 7.2 三种情况

| 情况 | $Z_{m2}$ | $\Gamma$ | 物理 |
|------|:---:|:---:|------|
| 匹配 | $= Z_{m1}$ | $0$ | 波无缝穿越，无反射 |
| 硬端（接极刚材料） | $\gg Z_{m1}$ | $\approx +1$ | 全反射同相。应力加倍，速度归零→对应开路 |
| 软端（接极软材料） | $\to 0$ | $\approx -1$ | 全反射反相。应力归零，速度加倍→对应短路 |

### 7.3 同种材料，变截面

材料相同（$E_1 = E_2 = E$，$\rho_1 = \rho_2 = \rho$），截面积从 $A_1$ 变为 $A_2$。

分界面的反射系数：

$$\Gamma = \frac{A_1 - A_2}{A_1 + A_2}$$

这是声学里**渐变喇叭**的原理——通过渐变截面实现力学阻抗匹配，减少反射。相当于传输线的渐变线阻抗变换器。

### 7.4 有损时的复数反射

如果一种或两种材料有损，$Z_{m1}^*$ 和 $Z_{m2}^*$ 都是复数 → $\Gamma(\omega)$ 也是复数 → 反射波有附加相位偏移。**这和传输线终端接复阻抗时反射系数是复数一样。**

## 八、有限长杆 — 特征值问题

### 8.1 两端固定

杆长 $L$，边界条件 $U(0) = U(L) = 0$。

通解 $U(x) = U_+ e^{-jkx} + U_- e^{+jkx}$。

$$U(0) = 0 \;\Rightarrow\; U_+ + U_- = 0 \;\Rightarrow\; U_- = -U_+$$

$$U(x) = U_+(e^{-jkx} - e^{+jkx}) = -2jU_+ \sin(kx)$$

$$U(L) = -2jU_+ \sin(kL) = 0$$

$$\sin(kL) = 0 \;\Rightarrow\; k_n L = n\pi \;\Rightarrow\; k_n = \frac{n\pi}{L}$$

固有频率：

$$\boxed{\omega_n = c \cdot k_n = \frac{n\pi c}{L} = \frac{n\pi}{L}\sqrt{\frac{E}{\rho}}}$$

固有振型（特征函数）：

$$\boxed{\phi_n(x) = \sin\!\left(\frac{n\pi x}{L}\right)}$$

- $n=1$：半波长正弦，整个杆朝同一方向摆动——**基频**
- $n=2$：全波长正弦，中点静止（节点）——二阶谐波
- $n=3$：三阶，两个节点——以此类推

**这和传输线两端短路时的共振模式完全一样——$V(x) = \sin(n\pi x/L)$，$f_n = nv/(2L)$。**

### 8.2 一端固定一端自由

$$U(0) = 0, \quad \frac{dU}{dx}\bigg|_{x=L} = 0$$

特征方程：$\cos(kL) = 0$ → $k_n L = \frac{(2n-1)\pi}{2}$

$$\omega_n = \frac{(2n-1)\pi c}{2L}$$

**对应传输线一端短路一端开路。**

### 8.3 两端自由

$$\frac{dU}{dx}\bigg|_{x=0} = 0, \quad \frac{dU}{dx}\bigg|_{x=L} = 0$$

特征方程：$\sin(kL) = 0$ → $k_n L = n\pi$

$$\omega_n = \frac{n\pi c}{L}$$

**对应传输线两端开路。**

## 九、受迫振动 — 传递函数

### 9.1 一端固定、一端受正弦力激励

杆长 $L$。$x=0$ 固定（$U(0) = 0$）。$x = L$ 处受到外力 $\Sigma(L) = F_0$（频域）。

求解空间 ODE，得到频域**传递函数**：

$$H(x,\omega) = \frac{U(x,\omega)}{F_0}$$

在激励点 $x = L$（该处位移和输入力的比值——类似"驱动点导纳"）：

$$H(L,\omega) \propto \frac{\tan(kL)}{kL}$$

极点在 $kL = \frac{(2n-1)\pi}{2}$，即 $\omega_n = \frac{(2n-1)\pi c}{2L}$——**这些就是共振频率。**

无阻尼时，在共振频率处 $H \to \infty$——一个无限小的力可以激起无限大的响应。**物理上当然不会无限大——材料会先进入塑性变形或断裂，但在数学上无阻尼模型在共振处是奇点。**

### 9.2 有阻尼时

$k \to k^* = \beta - j\alpha$：

$$H(L,\omega) \propto \frac{\tan(k^*L)}{k^*L}$$

$k^*$ 有虚部 $\alpha \neq 0$ → 共振处的 $\tan$ 函数是**有限值** → $H$ 在共振频率处有限。

**阻尼把极点从实轴上推开。** 这和 $RLC$ 电路中电阻 $R$ 把谐振峰的品质因数 $Q$ 压低完全一样：

| | 传输线 / RLC 电路 | 弹性杆 |
|---|---|---|
| 无阻尼共振 | $Q \to \infty$，极点纯虚 | 振幅 $\to \infty$，极点纯实 |
| 有阻尼共振 | $Q$ 有限，共振峰有限高度 | 振幅有限，$Q = 1/\gamma$ |
| 阻尼的角色 | $R$ 和 $G$ 吃能量 | $\eta$ 或 $\gamma$ 吃能量 |
| 谁控制 $Q$ | $R/(\omega L)$, $G/(\omega C)$ | $\eta\omega/E$（K-V）或 $\gamma$（滞弹性） |

## 十、抗震设计的频域逻辑

### 10.1 分析流程

```
地震时程 s(t)
      │
      ↓ 傅里叶变换
地震频谱 S(ω) —— 频域里地震能量怎么分布
      │
      ↓ × 结构传递函数 H(ω)
结构响应 U(ω) = S(ω)·H(ω)
      │
      ↓ 逆傅里叶变换
结构响应时程 u(t)
      │
      ↓ 峰值 → 与设计限值比较
通过 or 不通过
```

**这和传输线的 $Y(\omega) = X(\omega) \cdot H(\omega)$、反变换得到接收波形、和眼图模板比较——完全一样的流程。**

### 10.2 隔震 — 压低传递函数的高频部分

基础隔震：把建筑放在橡胶支座上，系统固有频率 $\omega_0$ 压至极低（~0.5 Hz）。地震主要能量在 1–10 Hz。

$|H(\omega)|$ 在 $\omega \gg \omega_0$ 时以 $\sim (\omega_0/\omega)^2$ 衰减 → 地震高频分量被大幅抑制。**相当于把建筑-地基系统变成一个极低截止频率的低通滤波器。**

### 10.3 调谐质量阻尼器（TMD）— 精确消灭共振峰

台北 101 顶部的大球。本质是一个弹簧-质量-阻尼系统，调谐到建筑的基频 $\omega_1$。地震时球和建筑反相振荡 → 球的反作用力正好抵消建筑运动 → $\omega_1$ 处的共振峰被压平。

**这就是弹性力学的"陷波器"——在特定频率上制造一个传输零点。**

## 十一、频域分析的完整流程（对照传输线）

| 步骤 | 传输线 | 弹性杆 |
|------|--------|--------|
| 1. 时域 PDE | 电报方程（两个一阶） | 波动方程（一个二阶） |
| 2. 傅里叶变换 | $v(x,t) \to V(x,\omega)$ | $u(x,t) \to U(x,\omega)$ |
| 3. 空间 ODE | $\frac{d^2V}{dx^2} = \gamma^2 V$ | $\frac{d^2U}{dx^2} + k^{*2}U = 0$ |
| 4. 传播常数 | $\gamma = \sqrt{(R+j\omega L)(G+j\omega C)} = \alpha+j\beta$ | $k^* = \omega\sqrt{\frac{\rho}{E^*}} = \beta-j\alpha$ |
| 5. 通解 | $V_+ e^{-\gamma x} + V_- e^{+\gamma x}$ | $U_+ e^{-jk^* x} + U_- e^{+jk^* x}$ |
| 6. 特征阻抗 | $Z_0 = \sqrt{(R+j\omega L)/(G+j\omega C)}$ | $Z_m^* = \sqrt{\rho E^*}$ |
| 7. 界面反射 | $\Gamma = \frac{Z_{02}-Z_{01}}{Z_{02}+Z_{01}}$ | $\Gamma = \frac{Z_{m2}^*-Z_{m1}^*}{Z_{m2}^*+Z_{m1}^*}$ |
| 8. 边界 → 共振 | 短/开路 → $f_n = \frac{nv}{2L}$（两端短路） | 固定/自由 → $\omega_n = \frac{n\pi c}{L}$（两端固定） |
| 9. 传递函数 | $S_{21}(\omega)$ | $H(x,\omega)$ |
| 10. 阻尼角色 | $R$ 和 $G$ → 复 $\gamma$ → 有限谐振峰 | $\eta$ 或 $\gamma$ → 复 $k^*$ → 有限共振峰 |

## 十二、频率响应的两种设计哲学

同一套波动方程，完全相反的设计目标：

```
                    通信系统 (UCIe/PCIe)              抗震系统 (桥梁/建筑)
                           │                                │
               ┌───────────┴───────────┐        ┌───────────┴───────────┐
               │                       │        │                       │
          信道低通滤波             去加重补偿   地震宽带激励          隔震+阻尼
         |H(f)| ↘ f↑           高通抬回     |S(f)| 1-10Hz         |H(f)| → 0
               │                       │        │                       │
               └───────────┬───────────┘        └───────────┬───────────┘
                           │                                │
                  目标：H_total(f) ≈ 1              目标：H_total(f) ≪ 1
                 （输出 = 输入，不失真）            （输出 ≪ 输入，不响应）
                           │                                │
              高频：必须保留（决定边沿）        高频：最好隔绝（破坏设备）
              共振：避免（谐振坑吞信号）        共振：极力避免（= 垮塌）
              阻尼：敌人（吃掉信号）            阻尼：朋友（吃掉共振能量）
```

**频域是波动方程的自然语言。** 无论是分析一条 2mm 的 UCIe 走线还是一座 200m 的桥，做的都是同一套操作：傅里叶变换 → 对每个频率解空间 ODE → 加边界条件 → 拼出完整频域响应 → （可选）逆变换回时域。
