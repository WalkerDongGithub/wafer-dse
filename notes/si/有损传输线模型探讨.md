# 有损传输线模型探讨

> 基于 Eric Bogatin, *Signal and Power Integrity — Simplified*, 2nd Ed., Ch7 & Ch9
> 目标：理解有损 RLCG 传输线的数学本质，以及 UCIe 电气参数在这个框架中的位置。

---

## 1. 建模起点：从"导线是理想导体"到"导线是有损传输线"

在直流或极低频率下，导线可以看作一根零电阻的连接。当频率升高，两个物理效应变得不可忽略：

1. **导线不再是无阻的** — 趋肤效应使高频电流只走导线表面，等效电阻随频率上升
2. **介质不再是无损的** — 绝缘材料中的交变电场会损耗能量（分子偶极子随电场反复翻转，产生热）

这两个效应被捕获在有损 RLCG 传输线模型中。

---

## 2. 物理结构：导线由什么组成？

一条信号线和它的回流路径构成了一根传输线。取一段无穷小长度 dx：

```
                     R·dx     L·dx
  i(x,t)    ────∕\/\/\────((((──────┬──── i(x+dx,t)
     →                              │
                 信号线 (signal)     │
     ←                              ├── C·dx
  ─────────────────────────────────┤
                                    ├── G·dx
     →                              │
     ←   回流路径 (return path)      │
  ─────────────────────────────────┴────
```

四个元件的物理意义：

| 元件 | 符号 | 单位 | 物理来源 | 频率依赖 |
|------|------|------|---------|---------|
| 串联电阻 | R | Ω/m | 导线金属电阻 + 趋肤效应 | R ∝ √f (趋肤) |
| 串联电感 | L | H/m | 信号线和回流路径之间磁场的储能 | 近似常数 |
| 并联电容 | C | F/m | 信号线和回流路径之间电场的储能 | 近似常数 |
| 并联电导 | G | S/m | 介质材料的介电损耗 | G ∝ f (ωC·tanδ) |

---

## 3. 支配方程：电报方程

对这一段 dx 分别用基尔霍夫电压定律（KVL）和基尔霍夫电流定律（KCL）：

### 电压定律 — 串联支路

沿信号线方向看，一小段 dx 上电压的降落来自两个部分：
- 电阻上的欧姆压降：iR·dx
- 电感上的感应压降：L·dx·∂i/∂t

```
v(x+dx,t) − v(x,t) = −[ R·i(x,t) + L·∂i(x,t)/∂t ]·dx

取 dx → 0 :

∂v/∂x = −R·i − L·∂i/∂t            —— 电报方程 (1)
```

### 电流定律 — 并联支路

在信号线和回流路径之间，一小段 dx 上损失的电流来自两个部分：
- 电容的充电/放电电流：C·dx·∂v/∂t
- 电导的漏电流：G·dx·v

```
i(x+dx,t) − i(x,t) = −[ G·v(x,t) + C·∂v(x,t)/∂t ]·dx

取 dx → 0 :

∂i/∂x = −G·v − C·∂v/∂t            —— 电报方程 (2)
```

这就是一维输电线上电压和电流走动的全部物理——**一切传输线行为都来自这两个一阶耦合偏微分方程。**

---

## 4. 频域形式：把偏微分方程变成常微分方程

正弦稳态下，所有量可写为复振幅形式：

```
v(x,t) = Re{ V(x)·e^(jωt) }
i(x,t) = Re{ I(x)·e^(jωt) }
```

代入电报方程 (1)(2)：

```
dV/dx = −(R + jωL)·I              —— (3)
dI/dx = −(G + jωC)·V              —— (4)
```

**关键观察**：R + jωL 是一个复阻抗（单位长度的串联阻抗）。G + jωC 是一个复导纳（单位长度的并联导纳）。

---

## 5. 解耦：二阶传播方程

对 (3) 再对 x 求导一次，代入 (4) 消去 I：

```
d²V/dx² = (R + jωL)(G + jωC)·V
```

定义**传播常数** γ：

```
γ = √( (R + jωL)(G + jωC) )       —— (5)
```

得到标准形式的二阶常微分方程：

```
d²V/dx² − γ²V = 0
```

这个方程的通解是人们熟知的形式——两个指数函数的线性组合：

```
V(x) = V₊·e^(−γx) + V₋·e^(+γx)     —— (6)

  V₊  = 正向传播波（从发送端向接收端走）
  V₋  = 反向传播波（从接收端向发送端反射回去）
```

---

## 6. γ 的分解：衰减与相位

γ 是复数。写为其实部和虚部：

```
γ = α + jβ

α = Re{γ} = 衰减常数 (Np/m 或 dB/m)
β = Im{γ} = 相位常数 (rad/m)
```

**(6) 的物理含义**：

```
V(x) = V₊·e^(−αx)·e^(−jβx) + V₋·e^(+αx)·e^(+jβx)

正向波：
  · 幅度：|V₊|·e^(−αx)              ← 随距离指数衰减
  · 相位：arg(V₊) − βx              ← 相位随距离线性旋转

反向波（反射）：
  · 幅度：|V₋|·e^(+αx)              ← 反向衰减
  · 相位：arg(V₋) + βx
```

**dB 形式**（工程常用）：

```
α(dB/m) = 20·log₁₀(e)·α(Np/m) ≈ 8.686·α(Np/m)

总损耗 (dB) = α(dB/m)·L
```

---

## 7. 特性阻抗 Z₀

从 (3) 和 (6)，把电流也用 V 表示：

```
I(x) = (γ/(R+jωL))·( V₊·e^(−γx) − V₋·e^(+γx) )
```

定义特性阻抗：

```
Z₀ = V₊/I₊ = (R + jωL)/γ = √( (R + jωL)/(G + jωC) )    —— (7)
```

**Z₀ 的物理意义**：如果导线无限长（没有反射），在导线上任何一点，正向电压波和正向电流波的比值就是这个常数。信号"看到"的瞬时阻抗就是 Z₀。

注意：**Z₀ 和长度无关**——它只取决于单位长度的 R、L、C、G 值。

---

## 8. 反射系数

在导线尽头 x = L 处，连了一个负载阻抗 Z_L。由边界条件：

```
V(L) = V₊·e^(−γL) + V₋·e^(+γL)
I(L) = (V₊·e^(−γL) − V₋·e^(+γL))/Z₀
V(L)/I(L) = Z_L
```

解出反射系数（Rabaey p160）：

```
Γ = V₋·e^(+γL) / V₊·e^(−γL) = (Z_L − Z₀) / (Z_L + Z₀)    —— (8)

  Z_L = Z₀  → Γ = 0       (匹配，无反射)
  Z_L = ∞   → Γ = +1      (开路，全反射、同相)
  Z_L = 0   → Γ = −1      (短路，全反射、反相)
```

---

## 9. 退化情况：无损传输线

当 R → 0, G → 0：

```
γ = jω√(LC)          → α = 0, β = ω√(LC)
Z₀ = √(L/C)           → 纯实数，与频率无关
v_phase = ω/β = 1/√(LC) → 相速度与频率无关，波形不畸变
```

这就是 Bogatin 第一层（LC 模型）的数学基础。UCIe Advanced Package 的 2mm 走线非常接近这个区域。

---

## 10. 退化情况：低损近似 — UCIe 的工作区域

当损耗不大时（R ≪ ωL, G ≪ ωC），把 γ 对 R/(ωL) 和 G/(ωC) 做小参数展开：

```
γ = jω√(LC)·√(1 + R/(jωL))·√(1 + G/(jωC))

   ≈ jω√(LC)·[ 1 + R/(2jωL) − (R/(jωL))²/8 + ... ]·[ 1 + G/(2jωC) − ... ]

   ≈ jω√(LC) + (R/2)·√(C/L) + (G/2)·√(L/C)

因此：

α ≈ R/(2Z₀) + (G·Z₀)/2        —— (9)

β ≈ ω√(LC)                    —— (10)

Z₀ ≈ √(L/C)                    —— (11)
```

**这是理解 UCIe 的关键公式**：

| 项 | 来源 | 频率依赖 |
|----|------|---------|
| R/(2Z₀) | 导体损耗（趋肤效应） | ∝ √f |
| (G·Z₀)/2 | 介质损耗 | ∝ f |

两个损耗项都随频率增长——**但介质损耗增长更快**（G ∝ f vs R ∝ √f）。

Bogatin p342 的结论：
> dielectric losses are greater than the conductor losses at frequencies above about 1 GHz.

在 UCIe 的 Nyquist 频率（2 GHz 到 16 GHz），**介质损耗占主导。**

---

## 11. R 和 G 的频率依赖

### 趋肤效应（Bogatin p372）

```
δ = 2.1 / √f    (δ: micron, f: GHz, 铜导体)

R(f) = ρ·L / (w·δ) ∝ √f

R_DC = 常数（极低频率）
R_AC(f) ≈ R_DC + k₁·√f     (k₁ 取决于导体材料和几何)
```

在 16 GHz 下，铜的趋肤深度 ≈ 0.5 μm。如果导线厚 2 μm，只有外圈 0.5 μm 参与导电。

### 介质损耗（Bogatin Ch9.4）

电介质在交变电场中，分子偶极子反复翻转，克服内摩擦而消耗能量。耗散因子 Df = tanδ 是材料属性：

```
G(f) = ω·C·tanδ = 2πf·C·Df

  SiO₂:          Df ≈ 0.005−0.01 (硅中介层)
  有机基板(ABF):  Df ≈ 0.01−0.02  (有机基板)
  FR4 (PCB):     Df ≈ 0.02
```

---

## 12. 将这些代入 UCIe 的参数

### UCIe Table 5-11 的损耗掩模

```
L(fN) = 20·log₁₀(|V(L)/V(0)|) = 20·log₁₀(e^(−α(fN)·L))
       = −(20/ln10)·α(fN)·L
       = −8.686·α(Np/m)·L

Advanced Package 4-16 GT/s:  L(fN) > −3 dB
Advanced Package 24-32 GT/s: L(fN) > −5 dB
```

代入 (9)：

```
L(fN) ≈ −8.686·[ R(fN)/(2Z₀) + G(fN)·Z₀/2 ]·L

其中 R(fN) = k₁·√fN
     G(fN) = 2π·fN·C·Df
```

### 这意味着什么？

| 参数 | 物理约束 |
|------|---------|
| R → fN 越大、R 越大 → 损耗越大 | 导线必须足够宽/厚来降低 R |
| G → fN 越大、G 越大 → 损耗更大（线性的，比 R 快） | 必须用低 Df 的介质（硅 > 有机 > FR4） |
| L → 越长 → 总损耗越大 | 25mm Standard vs 2mm Advanced 的损耗差了 12× |

### 为什么介质材料是关键的？

在 16 GHz (32 GT/s 的 fN)，假设 C ≈ 100 pF/m, Z₀ ≈ 50Ω：

```
硅介质 (Df=0.005):  G·Z₀/2 ≈ 2π·16e9·100e-12·0.005·50/2 ≈ 1.26 Np/m
有机基板 (Df=0.015): G·Z₀/2 ≈ 3.77 Np/m

→ 有机基板的介质损耗是硅中介层的 3 倍。

加上导体损耗 (≈ √f):
  Advanced (2mm):    α·L ≈ 0.003 Np ≈ 0.03 dB  ← 极低
  Standard (25mm):   α·L ≈ 0.1 Np ≈ 0.9 dB     ← 可接受但非零
```

这就是为什么 Advanced Package 可以用更宽松的损耗规格——距离短到损耗基本不存在。而 Standard Package 需要更严格的材料和走线设计。

---

## 13. 去加重（De-emphasis）：对频率依赖损耗的补偿

因为 α(f) 随频率增大，所以通道起到"低通滤波"的作用。高频分量被衰减得比低频分量多。

去加重的策略是：**在发送端人为地降低低频分量的幅度**，使得经过通道衰减后，所有频率分量的幅度变得均匀。

```
发送端:  低频分量幅度 = (1−C₊₁)·V, 高频分量幅度 = V
通道:    高频衰减 > 低频衰减
接收端:  低频幅度 ≈ 高频幅度 → 信号无畸变
```

UCIe Table 5-4 (p188) 给出了预设的去加重值——本质上是预先计算出的 C₊₁ 值，对应不同的通道特性。

---

## 14. 总结：从方程到 UCIe 参数

```
∂²V/∂x² = γ²V    (电报方程的二阶形式)

   γ = α + jβ

   α ≈ R/(2Z₀) + GZ₀/2   ──→  损耗掩模 L(fN) > -3dB / -5dB
                                   │
                                   ├── R: 趋肤效应 ∝ √f → 导体损耗
                                   └── G: 介质耗散 ∝ f  → 介质损耗

   β ≈ ω√(LC)           ──→  信号速度 v = 1/√(LC)
                                   2mm: 13ps, 25mm: 167ps

   Z₀ ≈ √(L/C)          ──→  Driver Impedance 22-28Ω 在匹配它

   Γ = (Z_L−Z₀)/(Z_L+Z₀) ──→  端接策略
                                   Advanced: Z_L 极高 (开路)→ Γ≈1 → 反射回源端→ 源端匹配吸收
                                   Standard: Z_L=Z₀ → Γ=0 → 接收端端接吸收

   去加重               ──→  补偿 α(f) 的频率依赖性 → ISI 减少 → 眼图打开
```
