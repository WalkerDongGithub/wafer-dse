# 损耗为何导致误码 — 不是波形变圆，是历史依赖

---

## 1. 先明确一个问题：接收端怎么判断 0 还是 1

接收端在每个 bit 周期（UI）的**中心点**采样一次电压。高于阈值 → 判 1。低于阈值 → 判 0。

**只要采样时刻的电压在正确的一侧，波形什么形状都无所谓。**

---

## 2. 如果损耗对所有 bit 的影响一样

假设信道只把每个 bit 的幅度乘以 0.8，上升沿也变慢了一点点——但对每个 bit 的影响完全相同。

接收端采样时刻的电压：1 → 0.8V，0 → 0V。仍然清晰可辨。**没问题。**

---

## 3. 真正的问题：损耗的影响对每个 bit 不一样

信道不是只衰减幅度——它**拉长上升沿**。上升沿变长到什么程度？

在 32 GT/s 下，1 UI = 31.25 ps。一个理想方波的上升沿 ≈ 5–10 ps。经过 25mm 走线（Nyquist 处带 ~3dB 损耗），高频分量被选择性削弱，上升沿退化到 ~25–35 ps——**和 UI 相当**。

此时发送"1 → 0"——电压从高往下掉。上升到一半——还没到底——下一个 bit 的采样时刻就到了。采样点电压**不是 0 V，而是 0.3 V**。接收端看到的"0"不是干净的 0，而是被前一个"1"的延迟下降沿污染的 0。

**前一个 bit 的状态影响了当前 bit 的采样电压。这就是 ISI。**

---

## 4. 一个具体的例子

发送序列：`1 0 1 1 0 1`

理想情况（无 ISI）：

```
采样电压：1.0  0.0  1.0  1.0  0.0  1.0
判定：   1    0    1    1    0    1
```

有 ISI（上升沿 ≈ UI）：

```
实际采样电压：    1.00  0.35  0.80  1.05  0.30  0.85
                   ↑     ↑     ↑     ↑     ↑     ↑
判定：             1     0     1     1     0     1
                                          ↖ 勉强正确（余量小）
```

还能对——但余量只有 0.15–0.20 V。如果叠加噪声（电源纹波、串扰、热噪声），0.35 V 随时可能被抬过阈值 → 0 被判成 1 → **误码**。

---

## 5. 更坏的序列：`1 0 0 1`

第二个 0：前一个 0 的下降沿刚稳定，第二个 0 很干净。

第一个 1 向第一个 0 切换：1 的尾巴还没收完 → 第一个 0 的采样电压被抬高。

第一个 0 向第二个 1 切换：第一个 0 被前面的 1 抬高 → 起点偏高 → 第二个 1 从更高的起点往上跳 → 上升时间够 → 采样正确。

**"1 → 0"是最脆弱的切换——因为 1 需要往下掉，损耗让下降沿变慢，而下一个 0 等不及。**

---

## 6. 所以损耗导致误码的链条是

```
α(f) 不平（高频比低频衰减多）
   ↓
上升沿和下降沿退化（变长）
   ↓
沿长度接近或超过 UI → 前一个 bit 的尾巴伸进了后一个 bit 的采样窗口
   ↓
采样电压不仅取决于当前 bit——还取决于前一个（甚至前几个）bit 的值
   ↓
特定序列下（特别是 1→0），采样电压偏移严重
   ↓
叠加噪声 → 偏移可能越过阈值 → 误码
```

---

## 7. 所以均衡补的是什么

不是补"波形变圆了不好看"——而是补**"上升沿太慢导致前一个 bit 的尾巴污染了后一个 bit 的采样窗口"**。

去加重压低连续同值的低频幅度 → 减少储存在线上的"缓慢衰落的能量" → 切换时尾巴缩短 → 采样窗口恢复干净。

**均衡的目标不是让方波重新变方——是让前一个 bit 对后一个 bit 采样时刻电压的影响趋近于零。**
