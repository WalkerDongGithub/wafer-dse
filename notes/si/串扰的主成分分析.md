# 串扰的主成分分析 — 用特征谱衡量串扰

---

## 1. 激励分解到特征基

$N$ 根线。特征模的基向量 $\mathbf{v}_1, \ldots, \mathbf{v}_N$（$\mathbf{LC}$ 的特征向量）。在某条线 $j$ 上发信号 $s(t)$：

$$\mathbf{V}(0) = [0,\ldots,0,1,0,\ldots,0]^T \cdot s(t) \quad\text{（只有线 j 非零）}$$

在特征基上投影：

$$\mathbf{V}(0) = \sum_{k=1}^{N} c_k \mathbf{v}_k$$

**$c_k = \mathbf{v}_k$ 的第 $j$ 个分量（对归一化特征向量）。** 物理含义：激励中第 $k$ 个模的"能量份额"。

---

## 2. 传播 → 频散 → 串扰

每个模以各自速度 $v_k$ 独立传播。在 $x = d$ 处：

$$\mathbf{V}(d,t) = \sum_{k=1}^{N} c_k \mathbf{v}_k \cdot s\!\left(t - \frac{d}{v_k}\right)$$

在目标线 $\ell$ 上的电压（$\ell \neq j$）：

$$V_\ell(d,t) = \sum_{k=1}^{N} c_k \cdot v_{k,\ell} \cdot s\!\left(t - \tau_k\right), \quad \tau_k = \frac{d}{v_k}$$

---

## 3. 串扰的基本机制

如果所有模速度相等：$\tau_1 = \tau_2 = \cdots = \tau_N$。此时：

$$V_\ell(d,t) = s(t - \tau)\! \underbrace{\sum_{k=1}^{N} c_k v_{k,\ell}}_{\text{这是矩阵的 }(\ell,j)\text{ 元在特征基下的恒等式}} = 0 \quad (\ell \neq j)$$

**"同一个基下两个不同正交行/列的投影和为零" — 等式成立不是因为耦合小，而是因为特征向量构成正交基。所有模同时到达 → 在远端完全重建了原始信号在 $\ell$ 处的零初始条件 → 无串扰。**

若速度不等 → 到达时间分散 → 重建不完美 → 残差 = 串扰。

**串扰 = 不同模到达时间的弥散导致的特征基重建误差。**

---

## 4. "主成分"视角

特征值 $\lambda_k$ 决定速度 $v_k = 1/\sqrt{\lambda_k}$。

设 $\lambda_k$ 分散在一个区间 $[\lambda_{\min}, \lambda_{\max}]$。速度分散度（相对展宽）：

$$\frac{\Delta \tau}{\bar{\tau}} \approx \frac{\sqrt{\lambda_{\max}} - \sqrt{\lambda_{\min}}}{\sqrt{\bar{\lambda}}} = \frac{\Delta(\sqrt{\lambda})}{\sqrt{\bar{\lambda}}}$$

**当所有 $\lambda_k$ 几乎相等 → 速度几乎相同 → 弥散极小 → 串扰极小。** 不需要"没有耦合"——只需要耦合是均匀的（$L_k/L_0 = C_k/C_0$ 对所有 $k$）。

如果有一条模 $m$ 的系数 $c_m$ 在激励中占主导（比如 $|c_m|^2 \gg \sum_{k \neq m} |c_k|^2$），那么信号主要沿这个模传播，其他模的贡献是微扰 → 串扰被压制。

---

## 5. 你能控制什么

**1. 压制非主导模的激发系数 $c_k$**：通过差分信号（$V_1 = -V_2$）只激发奇模——$c_k = 0$ 对偶模。这是让激励 "对齐" 单个特征向量。$N$ 根线更复杂——没有完美只激单个模的方法（除非你每根线都独立驱动特定的电压模式），但差分对是最简单的近似。

**2. 让所有特征值尽可能接近**：均匀介质 → $L_k/L_0 = C_k/C_0$ 对所有 $k$ → 所有 $\lambda_k$ 相等 → 零弥散 → 零 FEXT。这是封装设计的任务——选介电常数接近 1 或均匀的材料。

**3. 减小线长 $d$**：弥散效应和 $d$ 成正比。

**4. 减小互耦 $L_1, C_1$**：增大间距 → 互耦减小 → 矩阵更接近对角 → 特征值更接近 → 速度弥散更小。

---

## 6. 串扰的"频谱"解释

特征值 $\lambda_k$ 的分布 = 模速度的分布 = 串扰强度的频率依赖性。

$\lambda_k$ 密集 → 速度弥散小 → 所有模几乎同时到达 → 信号重建好 → 串扰小（低频好）。

$\lambda_k$ 分散 → 速度弥散大 → 到达时间展开 → 信号重建差 → 串扰大。

**这是多导体传输线的"频散关系"——$\mathbf{LC}$ 的特征谱分布直接决定串扰强度。**

---

## 7. 和 PCA 的类比

| PCA | 多导体传输线 |
|-----|-----------|
| 协方差矩阵 | $\mathbf{LC}$ 矩阵 |
| 主成分 | 特征模 $\mathbf{v}_k$ |
| 特征值 | $\lambda_k$ → 传播速度 $v_k$ |
| 数据在某主成分上的投影 | 激励在特征模上的系数 $c_k$ |
| 压缩/重建误差 | 串扰（速度不同 → 重建不完美） |

**PCA 中你扔掉小特征值对应的成分来压缩数据。多导体传输线中你扔掉（压制）非主导模来压制串扰。数学结构完全相同。**
