---

## 开篇：信号完整性研究的是什么？

**信号完整性（Signal Integrity）研究一个简单的问题：发送端发出的电压波形，经过导线传到接收端时，波形是不是还"认得出来"？**

如果波形基本不变 → 接收端能正确判断 0 和 1 → 信号完整。

如果波形严重变形 → 接收端判断出错 → **bit 错误**。

UCIe 电气层的所有参数——驱动器阻抗、通道损耗、串扰掩模、BER——本质上都是在描述"波形有多大概率会变形到认不出来的程度"。

## ① 传输线：导线在高速下不是"一根线"

### 核心观念转变

在直流或极低频率下，导线可以当作一根"理想的零电阻连接"——发送端加电压，接收端瞬间就看到电压。

但在 32 GT/s（UCIe 最高速率）下，一个 UI = 31.25 ps。光在这段时间里只能走约 9 毫米。**信号在导线上的传播时间是有限的——它不是"瞬间到达"，而是"沿着导线一步步传播"。**

**当信号的上升时间比信号在导线上的传播时间更短（或量级相当）时，这条导线就不再是一根"导线"，而是一条"传输线"。**

### Rabaey 的模型层次（教材 Ch4.4）

Rabaey 第 4 章（p133+）用了一个极好的递进模型来解释这个转变：

```
模型 1：理想导线
  任何时候 V(A) = V(B)。对 UCIe 不适用——走线太长。

模型 2：集总电容模型
  导线是一颗电容。上升时间 > 传播时间 × 20 时差不多对。
  UCIe 25mm 走线：传播时间 ≈ 167 ps；32 GT/s 下上升时间 ≈ 10 ps
  → 传播时间是上升时间的 16 倍 → 集总模型完全不对！

模型 3：集总 RC 模型
  导线是电阻 + 电容。传播延迟 ≈ 0.7 × R × C。
  用于片内互连（微米级），对封装级太粗糙。

模型 4：分布式 RC 线
  无穷多个小 RC 串联。Rabaey 4.4.4 节有详细推导。
  传播延迟 ∝ 长度²。这是"RC 主导"的导线。

模型 5：传输线
  每个无穷小段 = 电感 L + 电容 C（R 视为附加损耗）。
  信号以波的形式传播，速度 = 1/√(LC)。
  **这是 UCIe 唯一正确的模型。**
```

**对 UCIe 来说，关键的判断**：任何长度超过 ~1mm 的 32 GT/s 信号线，都必须作为传输线来分析。UCIe 的 2mm（Advanced）和 25mm（Standard）都在传输线范畴内。

**深入阅读**：Rabaey 4.4 节（p129-160），Bogatin Ch7（p209-280）。

## ② 特性阻抗：每根导线都有一个"电阻值"

### 本质

用 Bogatin 的话说（Ch7, p224）：

> The instantaneous impedance of a transmission line is the ratio of the voltage applied to the current that flows into the line at each instant in time.

**把导线想象成一根无限长的绳子。你在一端抖一下，一个波沿着绳子跑。绳子的"特性阻抗"就是：你用多大的力（电压）产生多大的抖动速度（电流）。**

一根均匀传输线，每个无穷小段有电感 L（单位长度）和电容 C（单位长度）。特性阻抗：

```
Z₀ = √(L/C)
```

**Z₀ 只取决于走线的几何形状和介质材料——和长度无关。** 2mm 的同一条走线，和 2m 的同一条走线，Z₀ 是一样的（损耗暂不考虑）。

### UCIe 里对应的参数

UCIe 不直接规定 Z₀（那是封装设计者决定的），但它规定了：

- **驱动器阻抗 22-28 Ω（Advanced）/ 27-33 Ω（Standard）** → 发送器必须匹配走线的 Z₀
- **VTF 损耗掩模（间接约束 Z₀）** → 如果 Z₀ 偏差太大，损耗掩模会过不了

在典型的硅中介层或有机基板走线中，Z₀ 通常在 **40-50 Ω** 左右。UCIe 的驱动器阻抗（22-28 Ω）低于 Z₀——这是因为 bump 和 pad 的寄生电阻串联进来后，总的源端阻抗应该 ≈ Z₀。

**深入阅读**：Bogatin 7.8-7.11 节（p224-238）。

## ③ 反射和端接：为什么 Advanced 和 Standard 处理不同

### 本质

当信号沿传输线到达一个"阻抗不连续"的位置（比如导线尽头连接到接收器），一部分能量会反射回来。Bogatin 第 8 章（p281-336）是理解这一点的最好章节。

**反射系数**：

```
Γ = (Z_load - Z₀) / (Z_load + Z₀)
```

- Z_load = Z₀ → Γ = 0 → **无反射**（匹配）
- Z_load = ∞（开路）→ Γ = 1 → **全部反射**
- Z_load = 0（短路）→ Γ = -1 → **全部反射（反相）**

### 端接策略

**端接 = 在接收端放一个电阻 = Z₀**，把信号能量全部吸收，不让它反射。

**源端端接 = 在发送端放一个电阻 = Z₀**，吸收从远端反射回来的能量，防止它在发送端再次反射。

### UCIe 的具体情况

**Advanced Package（2mm）**：传播时间 ≈ 13 ps，反射来回 ≈ 26 ps。32 GT/s 下 1 UI = 31.25 ps。**反射回来的时候，还处于同一个 UI 内**——在发送端就被源端阻抗吸收了，不影响后续 bit。

→ **不需要接收端端接。** 发送器阻抗（22-28 Ω）做源端匹配就够了。

**Standard Package（25mm）**：传播时间 ≈ 167 ps，反射来回 ≈ 334 ps > 10 UI。**反射回来的时候，第 11 个 bit 正在发送。** 源端阻抗吸收了这个反射，但它和第 11 个 bit 的信号叠加 → 干扰。

→ **必须接收端端接。** 信号到达接收端就被吸收，根本不产生反射。

### UCIe 里对应的参数

| UCIe 参数 | 对应概念 |
|----------|---------|
| Driver Impedance 22-28Ω（Advanced）| 源端匹配的电阻值 |
| Driver Impedance 27-33Ω（Standard）| 更接近 Z₀ 的源端匹配 |
| Advanced: unterminated Rx | 不需要接收端端接 |
| Standard: terminated Rx | 必须接收端端接 |

**深入阅读**：Bogatin 8.1-8.10 节（p281-305）。

## ④ 损耗：信号传得越远、频率越高，衰减越厉害

### 两种损耗来源

Bogatin 第 9 章（p337-404）。

**1. 导体损耗（趋肤效应）**

高频电流只在导体表面极薄的一层流动（趋肤深度 ∝ 1/√f）。频率越高 → 电流越集中在表面 → 有效截面积越小 → 电阻越大。

在 16 GHz（32 GT/s 的 Nyquist 频率），铜的趋肤深度 ≈ 0.5 μm。如果导线厚度是 2 μm，只有外圈的 0.5 μm 在导电 → 有效电阻远大于直流电阻。

**2. 介质损耗**

导线之间的绝缘材料（硅的 SiO₂、有机基板的 ABF）在高频下会吸收电场能量，转化为热量。介质的"耗散因子"（dissipation factor, Df）决定了这种损耗的大小。

硅的 Df 在 16 GHz 下约 0.005-0.01；有机基板材料的 Df 约 0.01-0.02。**有机基板的介质损耗比硅中介层高。**

### 损耗用 dB 表示

Bogatin 9.10-9.11 节（p371-384）：

```
Attenuation (dB) = 20 × log₁₀(V_out / V_in)
```

- -3 dB → V_out / V_in ≈ 0.71 → 收到 71% 的幅度
- -5 dB → V_out / V_in ≈ 0.56 → 收到 56% 的幅度
- -20 dB → V_out / V_in ≈ 0.1 → 收到 10% 的幅度

### 为什么 UCIe 规定的是"Nyquist 频率下的损耗"？

**Nyquist 频率 fN = 数据速率 / 2。** 这是因为在 NRZ 信号中，最高频率分量（101010 交替模式）正好是数据速率的一半。

规范在 fN 处规定损耗掩模，因为**如果 fN 的信号能过，所有更低频率的分量也差不多能过**。不需要每个频率都检查——只检查最关键的 Nyquist 频率。

### UCIe 里对应的参数

| UCIe 参数 | 含义 |
|----------|------|
| L(fN) > -3dB（4-16 GT/s Advanced）| Nyquist 频率损耗不超过 3dB |
| L(fN) > -5dB（24-32 GT/s Advanced）| 高速时放宽到 5dB |
| L(fN) 线性掩模（DC→fN）| 通道必须展示平滑频率响应——不能有谐振坑 |

**Standard Package 没有单独的损耗掩模**——因为它距离长（25mm），损耗自然更大。这由端接和均衡来补偿。

**深入阅读**：Bogatin 9.1-9.5 节（p337-360）、9.11 节（p376-384）。

## ⑤ 眼图：判断信号"能不能认出来"的可视化工具

### 本质

把所有可能的 bit 组合（000→001→010→011→...）叠加在示波器上，形成一张"眼睛"形状的图。

- **眼睛张开（open eye）** = 0 和 1 能分清 → 可以可靠采样
- **眼睛闭合（closed eye）** = 0 和 1 混在一起 → 无法区分 → bit 错误

### 眼图的宽度和高度

- **眼高（Eye Height）**：最坏情况下 0 和 1 之间的电压差
- **眼宽（Eye Width）**：最坏情况下采样时刻的"安全窗口"

**眼高太小 → 噪声会翻转 bit。眼宽太小 → 时钟抖动会导致在错误时刻采样。**

### UCIe 里的对应参数

| UCIe 参数 | 眼图上的体现 |
|----------|------------|
| 总抖动 ≤ 96/113 mUI pk-pk | 眼宽缩小——"安全采样窗口"变窄 |
| 通道损耗 > -3dB | 眼高缩小——信号衰减后 0 和 1 的间距变小 |
| 占空比误差 ≤ ±0.02 UI | 眼图的不对称——上半眼和下半眼大小不一致 |
| Lane 间偏移 ≤ ±0.02 UI | 64 张眼图的水平偏移——采样时刻必须覆盖所有 Lane |

**深入阅读**：Bogatin 9.15 节（p400-403）。Bogatin 这本书对眼图的直接讨论不多，补充材料看 PCIe 规范关于眼图掩模的部分——PCIe 规范定义了非常详细的眼图合规标准，UCIe 借用了其中的很多概念。

## ⑥ 串扰：一根线上的信号污染了旁边的线

### 本质

两根并排的导线之间有**互电容 C_m** 和**互电感 L_m**。一根线 AB 上的电压变化 → 通过 C_m 耦合到旁边的线 CD → 在 CD 上产生噪声。一根线 AB 上的电流变化 → 通过 L_m 在旁边的线 CD 上感应出电压。

Bogatin 第 10 章（p405-474）。

### 两种串扰

- **近端串扰（NEXT）**：在发送端附近的一侧测量到的串扰噪声
- **远端串扰（FEXT）**：在接收端附近的一侧测量到的串扰噪声

在 UCIe 的短距离场景（2mm），NEXT 和 FEXT 的量级接近。在更长的 PCB 走线上，FEXT 通常小于 NEXT。

### 串扰取决于什么？

1. **走线间距**：间距越大 → C_m 和 L_m 越小 → 串扰越小
2. **信号频谱**：频率越高 → 耦合越强 → 串扰越大
3. **并行长度**：并排走线越长 → 累积耦合越多 → 串扰越大

### UCIe 的串扰掩模为什么是"损耗函数"？

规范 Table 5-11 规定：XT(fN) < 1.5 × L(fN) - 21.5 且 XT(fN) < -23 dB。

**这是一个"联合约束"**：如果你的通道损耗大 → 信号弱 → 更容易被串扰污染 → 串扰限值必须更严格。损耗和串扰不是独立变量——Bogatin 10.17 节（p466-468）讨论了串扰和时序的关系。

### UCIe 里对应的参数

| UCIe 参数 | 约束什么 |
|----------|---------|
| XT(fN) < 1.5×L(fN) - 21.5 | 串扰低于损耗决定的阈值 |
| XT(fN) < -23dB（4-16GT/s）| 绝对上限 |
| XT(fN) < -24dB（24-32GT/s）| 高速时更严格 |

**深入阅读**：Bogatin 10.1-10.12 节（p405-448）、10.19 节（p473-474 跨 talk 减少方法总结）。

## ⑦ S 参数：描述"任何通道"的通用语言

### 本质

S 参数（散射参数，Scattering Parameters）描述一个"黑盒子"（比如你的封装走线）中每个端口的信号反射和传输特性。

Bogatin 第 12 章（p555-614）是学习 S 参数的最好入门。

**S 参数的核心思想**：一个 N 端口的网络，它的全部行为由 N×N 的 S 参数矩阵完全描述。每项 S_ij 表示"从端口 j 进入的信号，在端口 i 出来的幅度和相位"。

### 两个最重要的 S 参数

| S 参数 | 全称 | 含义 |
|--------|------|------|
| **S11** | 回波损耗（Return Loss）| 信号在端口 1 反射了多少 → 对应 UCIe 的"反射问题" |
| **S21** | 插入损耗（Insertion Loss）| 信号从端口 1 到端口 2 衰减了多少 → 对应 UCIe 的"损耗掩模" |

**回波损耗好（S11 很负，比如 <-20dB）= 几乎没有反射 → 阻抗匹配好。**

**插入损耗好（S21 接近 0dB）= 信号几乎没衰减 → 通道质量好。**

### 为什么 UCIe 用 VTF（电压传输函数）而不是直接规定 S 参数？

**VTF 本质上是 S21 的一个特定形式**：在特定的端口阻抗条件下（25Ω 发送器 + 0.2pF 接收器），测量从发送端到接收端的电压传输比。VTF 关注的只是"信号剩下多少"——不管反射。反射问题由驱动器阻抗和端接规范来约束。

**深入阅读**：Bogatin 12.1-12.6 节（p555-570）、12.9 节（p577-582）。

## ⑧ 均衡：补偿通道的"不公平"

### 本质

通道对高频衰减比对低频衰减更严重 → 高频分量的信号比低频分量弱 → 上升沿变缓 → 眼图闭合。均衡就是**在发送端预加重高频分量**或**在接收端放大高频分量**，补偿通道的不平。

Bogatin 9.16 节（p402-403）。

### UCIe 用的去加重（De-emphasis）

规范 p187-188：24 GT/s 和 32 GT/s **必须支持去加重**。16 GT/s **推荐**。

**去加重 = 发送端把低频分量的幅度降低（而不是把高频分量提高），让整个频谱经过通道衰减后变得平坦。** 表 5-4（p188）定义了具体的去加重预设值。

这需要功耗——发送器的输出级要能驱动不同的摆幅。**但规范把它作为 24/32 GT/s 的必备功能，因为在那些速率下，通道的高频衰减严重到不加均衡就满足不了 BER 指标。**

### UCIe 里对应的参数

| UCIe 参数 | 含义 |
|----------|------|
| Tx Equalization 必须支持（24/32 GT/s）| 通道的高频衰减必须被补偿 |
| 去加重预设值（Table 5-4）| 不同的通道特性用不同的补偿量 |
| 去加重准确度 ±0.5dB | 不能过度补偿（会引入新的失真） |

**深入阅读**：Bogatin 9.16 节（p402-403）。这本书对均衡的讨论比较简短，更多细节可以参考 PCIe 6.0 规范关于 FFE/DFE 的部分。

## 把这一切串起来：UCIe 电气层是怎么用这些概念的

回到 UCIe 的 Table 5-11（p201），现在你应该能读懂每一个量了：

```
Data Rate        4-16 GT/s              24/32 GT/s
─────────────────────────────────────────────────
VTF Loss         L(fN) > -3 dB          L(fN) > -5 dB
                   ↑                       ↑
            "信号在 Nyquist 频率     "高速时允许多损失
             至少剩 71% 幅度"         2dB——因为有去加重"

VTF Crosstalk    XT(fN) < 1.5L(fN)-21.5  XT(fN) < 1.5L(fN)-19
                 AND XT(fN) < -23dB      AND XT(fN) < -24dB
                   ↑                       ↑
            "串扰比信号弱至少        "高速时串扰限值更严格
             23dB，且如果损耗大        ——因为信号更脆弱"
             串扰必须更小"
```

**损耗掩模** 是利用 **S21（插入损耗）** 的概念在频域定义的。

**串扰掩模** 是利用 **NEXT/FEXT（近/远端串扰）** 的概念在频域定义的。

**驱动器阻抗 + 端接** 是利用 **反射理论** 来保证信号的单程传输干净。

**去加重** 是利用 **均衡** 来补偿高频损耗，保证眼图打开。

**BER** 是所有 SI 问题的终点——损耗 + 反射 + 串扰 + 抖动 → 眼图缩小 → 采样出错概率 = BER。

## 最后：你不需要成为 SI 工程师

你不需要会用 ADS 或 HFSS 做电磁仿真，不需要会跑 SPICE 瞬态分析。

**你需要的是：看到 UCIe/PCIe 规范里的一个电气参数，能立刻知道它对应哪个物理现象，以及这个参数变严或变松对系统意味着什么。**

- 看到 "-3dB" → 知道那是在说"信号在最高频率时还剩 70%"
- 看到 "22-28 Ω" → 知道那是在做源端匹配、抑制反射
- 看到 "XT < 1.5×L - 21.5" → 知道那是把损耗和串扰绑在一起约束
- 看到 "1e-15 BER" → 知道那是眼图闭合到某个程度时的"出错概率"

这就是这份讲义的目标。
