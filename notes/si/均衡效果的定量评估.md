# 均衡效果的定量评估 — 你怎么知道补了多少

---

## 1. 首先纠正一个说法

均衡不是"降低损耗"——**损耗是信道的固有属性，$\alpha(f)$ 还在那里。** 均衡是在发送端或接收端加一个反滤波器，让**整个链路的综合响应**变平。

$$H_{\text{total}}(f) = H_{\text{channel}}(f) \cdot H_{\text{eq}}(f)$$

$$H_{\text{channel}}(f) = e^{-\gamma(f)L}$$

目标：

$$|H_{\text{total}}(f)| \approx \text{常数}, \quad f \in [0, f_N]$$

---

## 2. 已知信道 $\alpha(f)$，加上均衡器后的剩余不平

### 去加重（发送端 FIR，一阶）

$$H_{\text{de-emph}}(f) = C_0 + C_{+1} \cdot e^{-j 2\pi f \cdot UI}$$

幅度响应：

$$|H_{\text{de-emph}}(f)| = \sqrt{C_0^2 + C_{+1}^2 + 2 C_0 C_{+1} \cos(2\pi f \cdot UI)}$$

$C_{+1} < 0$（压低连续同值）→ 在低频（$f \to 0$）幅度 = $|C_0 + C_{+1}| = 1 - |C_{+1}| < 1$；在高频（$f = f_N = 1/(2\cdot UI)$）$\cos(\pi) = -1$ → 幅度 = $|C_0 - C_{+1}| = 1$。

**去加重在低频衰减，高频全通——恰好和信道相反。**

综合响应：

$$|H_{\text{total}}(f)| = e^{-\alpha(f)L} \cdot |H_{\text{de-emph}}(f)|$$

---

## 3. 三个评价指标

### 指标 1：通带内的增益不平（Gain Flatness）

$$\Delta G = \max_{f \in [0, f_N]} |H_{\text{total}}(f)| - \min_{f \in [0, f_N]} |H_{\text{total}}(f)|$$

单位 dB。$\Delta G = 0$ → 完全平坦。$\Delta G \to 0$ 是均衡器设计的优化目标。

**未均衡时的 $\Delta G$ 通常就是 $\alpha(f_N)L$（dB）。均衡后 $\Delta G$ 应显著缩小。**

### 指标 2：残余 ISI — 脉冲响应的拖尾

发送一个孤立的 1（单个 UI 宽的脉冲），在接收端采样时刻 $t = 0$ 后的 $t = k \cdot UI$（$k = 1, 2, 3, ...$）测量残余电压。

$$ISI_{\text{post}}(k) = \frac{|h_{\text{total}}(k \cdot UI)|}{|h_{\text{total}}(0)|}$$

$ISI_{\text{post}}(1)$ = 前一个 bit 在当前 bit 采样时刻的残留比例。目标：趋近于 0。

**去加重只能压低 $ISI_{\text{post}}(1)$。DFE 可以消除 $ISI_{\text{post}}(1, 2, 3, ...)$。CTLE 降低所有后兆的包络。**

### 指标 3：眼图张开度

对所有可能的 bit 序列仿真（或实测）眼图，测量：

- **眼高（Eye Height）**：所有序列中，采样时刻 1 的最小电压 − 0 的最大电压
- **眼宽（Eye Width）**：所有序列中，0 和 1 的交叉点在时域上的最小间距

均衡前 vs 均衡后 → 眼高的增加量直接衡量均衡器的收益。

**眼高除以发送端信号幅度 = 归一化眼高。它决定噪声容限。眼高翻倍 = 可容忍的噪声翻倍。**

---

## 4. 数值示例 — UCIe 去加重 @ 32 GT/s

假设 $\alpha(f_N)L = 5\text{ dB}$（未均衡时的 Nyquist 频率衰减）。

无均衡时：$\Delta G \approx 5\text{ dB}$，低频全通过（0 dB 衰减），高频衰减 5 dB。

加 -2.2 dB 去加重（$C_0 = 0.888$，$C_{+1} = -0.112$）：

- DC 增益：$|0.888 - 0.112| = 0.776$ → $-2.2\text{ dB}$
- Nyquist 处增益：$|0.888 + 0.112| = 1.0$ → $0\text{ dB}$

综合响应：

- DC 处：$0\text{ dB} + (-2.2)\text{ dB} = -2.2\text{ dB}$
- Nyquist 处：$-5\text{ dB} + 0\text{ dB} = -5\text{ dB}$

$\Delta G = 5 - 2.2 = 2.8\text{ dB}$。不平从 5 dB 缩小到 2.8 dB。

**残余的 2.8 dB 不平是这个信道 + 这个去加重能达成的最佳状态。要进一步缩小，需要更大的去加重值或加 CTLE。**

---

## 5. 扩展到更复杂的均衡器

CTLE 的传递函数是模拟高通滤波器：

$$H_{\text{CTLE}}(f) = A_{DC} \cdot \frac{1 + j f/f_z}{1 + j f/f_p}, \quad f_z < f_p$$

DFE 不能简单地写成频域传递函数——它是非线性反馈。它的效果要通过脉冲响应的后兆消除量来评估。

---

## 6. 总结

$$\text{评价均衡效果} = \text{比较 } H_{\text{total}}(f) \text{ 的平坦程度}$$

三个指标：

- **增益不平** $\Delta G$：频域总体衡量
- **残余 ISI**：时域逐 bit 衡量
- **眼高增量**：最终的信号质量衡量

三者是同一个事实的三个角度——综合响应更平 → 残余 ISI 更小 → 眼更高。
