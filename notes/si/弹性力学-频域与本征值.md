# 频域分析与本征值问题 — 为什么两套方法都要用

---

## 一、先看两套方法对同一个杆做了什么

杆长 $L$，两端固定。波动方程：

$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad c = \sqrt{\frac{E}{\rho}}$$

$$u(0,t) = 0, \quad u(L,t) = 0$$

### 方法 A：频域分析（傅里叶变换）

对 $t$ 做傅里叶变换（$u(x,t) \to U(x,\omega)$，$\partial/\partial t \to j\omega$）：

$$\frac{d^2 U}{dx^2} + k^2 U = 0, \quad k = \frac{\omega}{c}$$

通解 $U(x,\omega) = A\sin(kx) + B\cos(kx)$。代边界条件 $U(0) = U(L) = 0$：

$$U(0) = 0 \;\Rightarrow\; B = 0$$

$$U(L) = 0 \;\Rightarrow\; \sin(kL) = 0$$

$$\Rightarrow\; k_n = \frac{n\pi}{L}, \quad n = 1, 2, 3, \dots$$

对应的解：

$$U_n(x) = \sin\!\left(\frac{n\pi x}{L}\right)$$

但注意——**这是 $k$ 必须取特定值才能满足边界条件。** 频域分析里 $\omega$ 从外面给，给什么 $\omega$ 就有什么 $k = \omega/c$，把 $k$ 代入 $U(x)$——一般不会恰好满足 $U(L) = 0$。只有 $\omega = \omega_n = c k_n$ 时边界条件才被满足。

频域分析的全解（受迫振动，有外力时）：

$$u(x,t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} U(x,\omega) \cdot e^{j\omega t} d\omega$$

$U(x,\omega)$ 是每个频率下空间 ODE 的解（包含了与该频率的外力对应的特解）。

### 方法 B：分离变量法

设 $u(x,t) = \phi(x) \cdot T(t)$，代入波动方程：

$$\phi \cdot \ddot{T} = c^2 \phi'' \cdot T$$

除以 $\phi T$：

$$\frac{\ddot{T}}{T} = c^2 \frac{\phi''}{\phi}$$

左边只含 $t$，右边只含 $x$。两边相等 → 双方都等于同一个常数。记这个常数为 $-\omega^2$：

$$\ddot{T} + \omega^2 T = 0 \quad\text{时间部分}$$

$$\phi'' + k^2 \phi = 0, \quad k^2 = \frac{\omega^2}{c^2} \quad\text{空间部分}$$

空间部分加上边界条件 $\phi(0) = \phi(L) = 0$——**这是一个本征值问题**：

$$\boxed{\phi'' + k^2 \phi = 0, \quad \phi(0) = 0, \quad \phi(L) = 0}$$

解之：

$$\phi(x) = A\sin(kx) + B\cos(kx)$$

$$\phi(0) = 0 \;\Rightarrow\; B = 0$$

$$\phi(L) = 0 \;\Rightarrow\; \sin(kL) = 0 \;\Rightarrow\; k_n L = n\pi$$

$$\boxed{k_n = \frac{n\pi}{L}, \quad \omega_n = c k_n = \frac{n\pi c}{L}}$$

对应的本征函数：

$$\boxed{\phi_n(x) = \sin\!\left(\frac{n\pi x}{L}\right)}, \quad n = 1, 2, 3, \dots$$

时间部分：$T_n(t) = A_n\cos(\omega_n t) + B_n\sin(\omega_n t)$

全解（自由振动，无外力）：

$$\boxed{u(x,t) = \sum_{n=1}^{\infty} \left[A_n\cos(\omega_n t) + B_n\sin(\omega_n t)\right] \sin\!\left(\frac{n\pi x}{L}\right)}$$

## 二、两套方法的关系

**形式上的"巧合"**：频域分析解空间 ODE 时得到 $\sin(kL) = 0$，分离变量法解空间 ODE 时得到完全相同的 $\sin(kL) = 0$。这不是巧合——**两个方法在解同一个空间 ODE。** 区别在于 $\omega$ 的身份：

| | 频域分析 | 分离变量法 |
|---|---|---|
| $\omega$ 是 | **参数**——你手动扫，给什么就算什么 | **本征值**——边界条件"挑"出来的离散值 |
| $\omega$ 的取值范围 | **连续**：任意实数值 | **离散**：只有 $\omega_n = n\pi c/L$ |
| 空间解的形态 | 对任意 $\omega$ 都是 $A\sin(kx) + B\cos(kx)$ | 和频域完全相同 |
| 边界条件的作用 | 确定积分常数 $A,B$ | 确定积分常数 + **选出允许的 $k_n$** |
| 最终叠加方式 | $\int U(x,\omega)e^{j\omega t} d\omega$（连续积分） | $\sum_n \phi_n(x)T_n(t)$（离散求和） |

**两者给出同一个 $u(x,t)$。** 原因：在有界域中，傅里叶逆变换的连续积分 $\int d\omega$ 退化为对复平面上极点的留数和——留数和就是 $\sum_n$。连续谱塌缩成离散谱。

## 三、本征值到底是什么

### 3.1 数学定义

空间 ODE + 边界条件构成一个**本征值问题**：

$$\phi'' + \lambda \phi = 0, \quad \phi(0) = 0, \quad \phi(L) = 0$$

其中 $\lambda = k^2$。

**本征值 $\lambda_n$**：让这个边值问题有**非零解** $\phi(x) \not\equiv 0$ 的那些 $\lambda$。

### 3.2 为什么叫"本征"

对于随便一个 $\lambda$，通解是 $\phi(x) = A\sin(\sqrt{\lambda}x) + B\cos(\sqrt{\lambda}x)$。代入 $\phi(0) = 0$ 得 $B = 0$。代入 $\phi(L) = 0$ 得：

$$A\sin(\sqrt{\lambda}L) = 0$$

- 若 $\lambda \neq \lambda_n$：$\sin(\sqrt{\lambda}L) \neq 0$ → $A$ 必须为 $0$ → $\phi(x) \equiv 0$。平凡解——物理上没意义，杆没有在任何地方动。
- 若 $\lambda = \lambda_n = (n\pi/L)^2$：$\sin(\sqrt{\lambda}L) = 0$ → $A$ 可以是任意常数 → $\phi_n(x) \not\equiv 0$。**非零解存在。**

**本征值就是那些让系统"允许"一个非零空间形态的特殊数值。** 换一个 $\lambda$，系统说"不行，唯一解就是零"。在 $\lambda_n$ 上，系统说"可以存在"。

### 3.3 物理含义

$$\boxed{\text{本征值 } \lambda_n = k_n^2 = \left(\frac{n\pi}{L}\right)^2 = \left(\frac{\omega_n}{c}\right)^2}$$

- $k_n$：杆能"自然保持"的空间频率（波数）
- $\omega_n$：杆的**固有频率**——杆"想"在这些频率上振荡
- $n = 1$（基频）：最小波数，最低频率，最简单的空间形态
- $n \to \infty$：越来越复杂的空间形态，越来越高的频率

**本征函数 $\phi_n(x)$ 就是杆在这些固有频率上的"振型"**——杆上每一点的振动幅度比例。$\phi_1(x) = \sin(\pi x/L)$：两端为零、中间最大——基频振动。$\phi_2(x) = \sin(2\pi x/L)$：中点为零（节点）、两段反相——二阶模态。

## 四、频域分析的强项 — 受迫振动与传递函数

### 4.1 你关心的是"外界给什么，系统回什么"

地震来了（外力已知，宽带频谱），桥怎么动？频域分析天然适合：

$$U(x,\omega) = H(x,\omega) \cdot F(\omega)$$

每个频率独立算响应，频谱拼起来就是时域响应。**不需要知道本征值——把外力频谱里的每一个 $\omega$ 代入空间 ODE 求解就行。**

### 4.2 共振在频域分析里怎么体现

算 $H(x,\omega)$ 时，$\omega$ 扫过 $\omega_n$ 附近 → $H$ 急剧增大（无阻尼时发散）。你不需要事先知道 $\omega_n$——$H(\omega)$ 自然"暴露"共振频率在哪。**本征值在频域分析里不是输入，是输出。**

---

## 五、分离变量法的强项 — 模态的物理直觉与降维

### 5.1 你关心的是"杆自己能怎么动"

杆被敲了一下（初始条件给了位移和速度分布），然后自由振动——没有外力。分离变量法天然适合：

$$u(x,t) = \sum_{n=1}^{\infty} c_n \phi_n(x) e^{j\omega_n t}$$

$$c_n = \frac{\int_0^L u(x,0) \cdot \phi_n(x) dx}{\int_0^L \phi_n^2(x) dx}$$

把初始条件展开成模态的加权和 → 每个模态以自己固有的频率振动 → 全解就是所有模态的叠加。**不需要逐频率解空间 ODE。**

### 5.2 模态截断 — 把无穷维变成有限维

实际工程中，一个复杂的结构（桥、机翼），空间离散化后可能有上百万个自由度。但你只关心前 10–50 阶模态（更高的频率在实际中激发不出来，或者阻尼严重）。分离变量法允许你只保前 $N$ 个本征函数，把 PDE 截断成 $N$ 个互相解耦的 ODE：

$$u(x,t) \approx \sum_{n=1}^{N} q_n(t) \cdot \phi_n(x)$$

这叫做**模态叠加法（modal superposition）**。$q_n(t)$ 是每个模态的"振幅"。从无穷维 PDE → 有限个 ODE → 数值求解成本降几个数量级。

**频域分析做不到这种"自然截断"**——因为频域里 $\omega$ 是连续的，你需要对全频谱积分才能得到时域解。

## 六、回到传输线 — 你早就见过本征值了

### 两根耦合传输线

$$\frac{d^2}{dx^2}\begin{bmatrix} V_1 \\ V_2 \end{bmatrix} = \mathbf{A} \begin{bmatrix} V_1 \\ V_2 \end{bmatrix}$$

对角化 $\mathbf{A}$：

$$\mathbf{A} = \mathbf{T} \begin{bmatrix} \gamma_1^2 & 0 \\ 0 & \gamma_2^2 \end{bmatrix} \mathbf{T}^{-1}$$

**$\gamma_1^2$ 和 $\gamma_2^2$ 就是 $\mathbf{A}$ 的本征值。** 对应的本征向量 $[1,1]$（偶模）和 $[1,-1]$（奇模）就是本征函数在离散 $2\times 2$ 空间里的版本。

| | 传输线（2 线） | 弹性杆（连续） |
|---|---|---|
| 算子 | $\mathbf{A} \in \mathbb{C}^{2\times 2}$ | $d^2/dx^2$（微分算子） |
| 本征值 | $\gamma_1^2, \gamma_2^2$ | $k_n^2 = (n\pi/L)^2$ |
| 本征向量/函数 | $[1,1]$, $[1,-1]$ | $\sin(n\pi x/L)$ |
| 模式数 | 2（有限维） | $\infty$（无穷维） |
| 对角化后 | 两个独立 ODE，各有自己的 $\gamma$ 和 $Z_0$ | 无穷个独立 ODE，各有自己的 $\omega_n$ |

**传输线是有限维的本征值问题，弹性杆是无穷维的本征值问题。数学结构完全一样。**

## 七、两套方法的关系图

```
                        波动方程
                  ∂²u/∂t² = c² · ∂²u/∂x²
                  + 边界条件 + 初始条件
                            │
            ┌───────────────┴───────────────┐
            ↓                               ↓
     频域分析                           分离变量法
   对 t 傅里叶变换                    设 u = φ(x)·T(t)
            │                               │
            ↓                               ↓
    d²U/dx² + k²U = 0             φ'' + k²φ = 0
    k = ω/c (连续参数)             φ(0) = φ(L) = 0
            │                      (本征值问题)
            │                               │
            ↓                               ↓
   对每个 ω 解 U(x,ω)             k_n = nπ/L (离散)
            │                    φ_n(x) = sin(nπx/L)
            │                    ω_n = c·k_n
            │                               │
            ↓                               ↓
   受迫振动：                      自由振动：
   u = ∫ U(x,ω)·e^{jωt} dω        u = Σ c_n φ_n(x)·e^{jω_n t}
            │                               │
            ↓                               ↓
     连续谱 + 传递函数               离散谱 + 模态正交性
            │                               │
            └───────────────┬───────────────┘
                            │
                            ↓
              两者等价：在有界域中
              ∫ dω 的极点留数 = Σ_n
```

## 八、什么时候用哪套方法

| 场景 | 频域分析 | 分离变量法 |
|------|:---:|:---:|
| 外力驱动（地震响应、声波激励） | ✓ 天然适合 | 可用，但需把外力投影到模态上 |
| 自由振动（敲一下、弹拨、初始变形释放） | 别扭 | ✓ 天然适合 |
| 传递函数 / 频率响应 | ✓ 直接给出 $H(\omega)$ | 需额外步骤 |
| 关心共振频率和振型 | $H(\omega)$ 的峰值 → 暴露共振 | ✓ 直接给出 $\omega_n$ 和 $\phi_n(x)$ |
| 数值降维（模型简化） | 不直接 | ✓ 模态截断 |
| 关心宽带信号的完整波形 | 逆傅里叶变换 | 模态叠加 |
| 无限域（波的传播、辐射） | ✓ 连续谱天然适合 | 离散谱 → 不适用（需辐射边界条件） |
| 有限域 + 复杂边界 | 可用 | ✓ 本征函数族给出结构化的基 |
| 非线性系统 | 困难（频率混叠） | 可用（非线性模态） |

**实际工程中两套方法混着用**：先用分离变量法（或有限元的模态分析）算出前几十阶固有频率和振型，然后用模态叠加法 + 频域的外力频谱计算响应。频域给激励，模态给结构——分工明确。

---

## 九、一句话

**频域分析是你主动扫 $\omega$ 看响应——本征值是"扫出来的"共振峰。分离变量法是让边界条件自己"挑"出固有频率——本征值是"挑出来的"离散频谱。同一个空间 ODE，两套进入方式，给出同一个 $u(x,t)$。选择哪套取决于你关心的是"系统对外力的反应"还是"系统自身的性格"。**
